# 자산·지출

`/income`에서 기존 비밀번호 기록장에 연결한 메소 흐름을 관리합니다.

- `AssetPage.tsx`: 현황·지출·목표 입력과 표시
- `useAssetLedger.ts`: 서버 조회·저장, 충돌 및 오류 처리
- `asset-model.ts`: BigInt 잔액·활동일 순수익·목표 계산
- `AssetTrends.tsx`: 7/30/90일 차트와 정확한 금액 표
- `contracts/ledger/finance-schema.ts`: 클라이언트·서버 공유 검증과 타입
- `server/ledger/finance-store.ts`: 기록장별 조회와 revision 조건부 저장

시작 잔액 이전 수입은 현재 잔액에 더하지 않습니다. 날짜만 있는 시작일 사냥·보스 기록은 사용자가 포함 여부를 결정합니다. 기준 저장 뒤 새로 입력한 당일 지출·판매에는 생성 시각을 사용합니다.

사냥 순감소도 지출·순수익에 반영하며 사냥 차액에 포함된 수동 지출을 다시 차감하지 않습니다. 이 지출은 목록에 남아 수정·삭제할 수 있습니다. 판매 확인한 실수령액만 자산에 포함하고 예상 물욕템 가치는 제외합니다. 잔액 조정은 수입으로 분류하지 않습니다.

통계는 시작 잔액 설정 여부와 무관하게 기록을 집계합니다. 미기록일은 차트에서 연결하지 않으며 알려진 잔액만 이어 표시합니다. 목표 예상치는 실제 달력 일수가 아닌 최근 기록된 활동 횟수 기준입니다.

기존 `model.ts`는 이전 수입 집계 계약과 회귀 테스트를 위해 보존합니다. 강화비 API 가져오기는 포함하지 않습니다.
