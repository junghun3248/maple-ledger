# 수입·목표

`/income`에서 기록장에 저장된 사냥·보스 기록을 그래프로 보고 목표를 관리합니다.

- `IncomeGoalsPage.tsx`: 페이지 조립 (목표 → 수입 그래프)
- `GoalsPanel.tsx`: 나의 다음 목표 카드, 목표 카드·만들기/수정·보유 메소 입력 대화상자
- `IncomeChart.tsx`: 7일~1년 누적 수입 그래프(사냥·보스·전체)와 날짜별 금액
- `model.ts`: 날짜별 사냥 차액·보스 정산액 누적 계산
- `asset-model.ts`: 목표 진행률(`goalProgress`), 진행 기준 금액(`goalBase`), 예상 기간 계산
- `useAssetLedger.ts`: 기록장 조회·저장(`finance-read`/`finance-save`)

목표 진행 기준은 보유 메소를 입력했으면 `입력값 + 이후 기록 수입`, 입력하지 않았으면 `지금까지 기록한 수입`입니다. 예전 자산·지출 화면에서 저장한 지출·잔액 조정·판매 기록은 DB에 그대로 남아 있지만 화면과 계산에서는 쓰지 않습니다.
