# 강화 비용 (스타포스·잠재능력 이력)

`/income`의 **강화 비용** 패널에서 넥슨 확률형 이력 API로 강화에 쓴 메소를 계산해 기록에서 뺀다.
처음 설계와 비용 정규화는 Codex(2026-11-11)가 만들었고, Claude가 현재 화면 구조에 맞게 옮겼다.

## 구성

- `contracts/ledger/enhancement-schema.ts`: 이력 조회·장비 레벨 조회 요청과 정규화 응답 계약
- `server/ledger/enhancement-history.ts`: 넥슨 `history/starforce`, `history/potential` 페이지 조회와 정규화, 장착·프리셋 장비 레벨 조회
- `features/income/enhancement-model.ts`: 비용표, 비용 계산, 이력 ID 해시와 중복 제거, 날짜별 합계
- `features/income/EnhancementPanel.tsx`: 기간 조회 → 조건 확인 → 기록 반영, 날짜별 삭제
- 저장은 기존 `finance` 저장(기록장 ID·revision 검증)을 쓴다. DB 마이그레이션은 없다.

## 반영 방식

- 계산 비용은 `finance.expenses`에 `category: 'enhancement'`, `calculated: true`로 저장한다.
- `dailyIncome`, `incomeSeries`가 이 비용을 빼므로 목표 진행률·예상 기간·수입 그래프·홈 요약이 모두 같은 기준을 쓴다.
- `사냥 전후 메소에 이미 포함됨`을 선택하면 저장은 하되 다시 빼지 않는다(`huntIncluded`).
- 예전 자산 화면의 수동 지출은 계산에 쓰지 않는다.

## 계산 범위와 한계

- 비용표가 바뀐 2026-10-22 이후 이력만 계산한다. 실제 차감액이 아닌 **추정값**이다.
- 잠재능력: 메소 잠재능력·에디셔널 재설정만. 재설정 **전** 등급과 장비 레벨로 계산하고, 결과 옵션 3개는 1회, 9개는 3회로 본다.
- 스타포스: 이력에 장비 레벨이 없어 현재 장착·프리셋 장비에서 같은 이름의 레벨을 찾는다. 못 찾으면 화면에서 입력한다.
- 레벨은 10 단위로 내린다. MVP·PC방 할인은 사용자가 선택하며 17성 미만 시도에만 적용한다.
- 이벤트 비용 할인은 적용 범위를 확인할 수 있을 때만 반영한다. 파괴 방지는 15~17성에서 기본 비용 2배를 더한다.
- 슈페리얼, 주문서·특수 재화, 특수 필드, 프로텍트 실드, 복구·전승, 범위를 알 수 없는 이벤트는 계산에서 뺀다.
- 파괴 후 장비 구입·복구 비용은 포함하지 않는다.

## 조회와 저장

- 한 번에 최대 31일. 날짜·종류별로 페이지를 순서대로 읽고 호출 사이 0.7초 쉰다. 서버는 기록장별 분당 120회로 제한한다.
- 모든 페이지를 읽은 뒤에만 반영할 수 있다. 오류나 반복 커서가 나오면 아무것도 저장하지 않는다.
- 종류와 공식 이력 ID의 SHA-256 해시를 지출 ID로 써서 같은 이력을 두 번 빼지 않는다.
- 날짜별로 지운 비용은 조건을 바꿔 다시 불러올 수 있다. 예전 데이터의 `ignoredEnhancements`는 계속 존중한다.
- API 키는 브라우저에만 저장하며(선택), 서버는 넥슨 호출에만 쓰고 저장·응답하지 않는다.
