# 2026-11-06 공통 레이아웃과 보스 카드

- 사이트 이름은 상단 메뉴에 한 번만 표시한다. 사냥·보스·수입·강화·캐시 페이지의 제목, 설명, 기록장 버튼을 공통 PageHeading으로 통합했다.
- 본문 최대 너비, 좌우 여백, 제목 크기와 모바일 배치를 통일했다.
- 캐릭터 프레임을 데스크톱 144px, 모바일 112px로 늘리고 이미지 내부 여백을 고려해 표시 배율을 조정했다.
- 주요 보스 18종의 25px 초상을 66×67px 원본으로 교체했다. 카드의 이름·인원·시간 글자와 클릭 영역을 확대했다.
- 보스 이미지 출처: https://meso.kr/boss/lotus.png 및 동일 공개 경로의 각 보스 파일. 메이플스토리 게임 이미지 권리는 NEXON에 있다. 그 외 7종은 기존 원본을 유지한다.
- 기록 저장, API 조회, 정산 계산 및 DB 구조는 변경하지 않았다.

검증: TypeScript, 기존 57개 테스트 통과. 변경 TSX ESLint 오류 없음(기존 장비 img 경고 1건). 로컬 미리보기에서 공통 제목과 보스 카드 배치를 확인했다.
