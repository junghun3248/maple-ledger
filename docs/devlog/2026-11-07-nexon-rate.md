# 넥슨 캐릭터 조회 호출 제한 대응

개발 단계 키의 초당 5회 제한에 비해 기존 배치는 최대 8명을 동시에 조회했습니다.
월드 목록은 성공하지만 전투력 조회가 다수 실패할 수 있는 경로를 수정했습니다.

- 요청별 넥슨 호출 시작 간격 300ms, 스케줄러·이미지 요청에도 적용
- 429 응답은 1초 대기 후 한 번만 재시도
- 배치의 전체 외부 조회 시간 제한 18초
- 화면에 한도 초과·키 오류·데이터 준비 중 등 안전한 오류 사유 표시
- 키와 원본 오류 응답은 로그나 화면에 공개하지 않음

같은 키를 여러 탭이나 다른 서비스에서 동시에 사용하는 경우와 일일 한도 초과는
여전히 실패할 수 있습니다. 성공 응답을 위조하거나 전투력 조건을 우회하지 않습니다.

[넥슨 호출 한도 안내](https://openapi.nexon.com/en/guide/prepare-in-advance/)

모의 API로 간격, 429 재시도, 영구 오류 재시도 없음 및 기존 배치 동작을 검증합니다.
