# 2026-11-04 보스 아이콘과 메소 수입 추이

- 캐릭터별 보스 목록을 초상 아이콘·난이도·인원 중심으로 정리하고 구성 변경 바로가기를 추가했다.
- 환산 보스 배율과 기준 시간을 입력하면 같은 배율의 파티원이라는 가정으로 시간을 계산한다. 개인 배율 × 인원으로 합산하며, 배율 미입력 보스는 합계 누락 수를 표시한다.
- 환산 배율을 자동 수집하는 연동은 제공하지 않는다. 환산 확인 링크와 직접 입력을 제공한다. 기본 기준은 20분이며 변경 가능하다.
- 배율은 기록장 보스 데이터의 선택 필드로 저장한다. 동일 난이도 다음 주 스케줄러 등록 시 이전 값을 이어 쓰며 기존 기록과 호환된다.
- 메소 수입 추이 메뉴에 10·30·90·365일 누적 그래프와 날짜별 금액 표를 추가했다.
- 사냥 전후 메소 차이와 저장된 보스 결정석·획득 드롭 정산액을 기록 날짜로 합산한다. 장비 평가액이나 조각 환산액을 포함하지 않는다.
- 실제 보유 자산이나 현금 가치가 아닌 기록 기반 누적 수입이며 보스의 미처치 계획도 기존 정산 규칙에 따라 포함된다.

시간은 기준 분 × 100 ÷ (개인 배율 × 인원)이다. 고정 패턴·이동·입장 시간과 파티원 스펙 차이는 반영하지 않는다.
