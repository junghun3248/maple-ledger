# 2026-10-30 · 보스 모아보기

밝은 가계부 테마를 유지하면서 캐릭터별 보스와 수익을 한 화면에 모았습니다. 보스 버튼을 누르면 획득 아이템, 인원, 판매가를 입력하는 상세 창이 열립니다.

- 주간·월간 보스 탭, 표시할 캐릭터 선택, 난이도 배지와 인원 요약
- 데이터 메뉴에 서버 저장·불러오기·파일 백업·복원 통합
- API 조회 결과를 캐릭터 카드로 선택하고 저장된 키는 재사용
- 같은 주의 다른 날짜에 저장된 보스도 구성 수정에서 편집
- 판매가 입력 중 수익 요약 갱신 오류 수정
- 사냥 기능과 기존 저장 형식 유지

검증: 수익·스케줄러·기록장·모아보기 자동 테스트 및 로컬 브라우저에서 보스 상세 입력과 수익 반영 확인.
