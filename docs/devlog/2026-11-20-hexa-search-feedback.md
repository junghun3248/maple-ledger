# 2026-11-20 헥사 닉네임 검색과 건의 게시판

작성: Claude

## 헥사 닉네임 검색

- 헥사 계산기에 닉네임 검색을 추가했습니다. 사이트 운영 키(Cloudflare Secret `NEXON_API_KEY`)로 `id` → `character/basic` → `character/hexamatrix` → `character/skill`(6차)을 읽습니다(서버 액션 `hexa-search`).
- 개인 키로 내 캐릭터 목록에서 고르는 기존 방식은 접어 둔 칸으로 남겼습니다.
- 사이트 키의 하루 한도를 지키려고 IP당 1분 10회, 사이트 전체 하루 1,000회로 검색을 제한합니다. 키가 없으면 503과 함께 개인 키 사용을 안내합니다. 키는 응답·로그에 넣지 않습니다.

## 건의·제보 게시판

- 상단 "제보" 버튼을 디스코드 대신 새 페이지 `/feedback`으로 연결했습니다.
- 누구나 300자 이내로 글을 남기고, 운영자는 비밀번호(Cloudflare Secret `FEEDBACK_ADMIN_PASSWORD`)로 답글·삭제를 합니다.
- 도배 방지: IP당 1분 1개·하루 10개, 전체 하루 300개. 링크가 들어간 글은 막습니다. 운영자 비밀번호 시도는 IP당 10분 10회로 제한합니다.
- 작성자 정보(IP 등)는 저장하지 않습니다.
- 새 테이블 `feedback_posts`(`drizzle/0004_feedback-posts.sql`). 기존 테이블은 바꾸지 않습니다. 저장소 규칙(모든 열 NOT NULL)에 맞춰 답글이 없으면 빈 문자열·0으로 둡니다.
- 기존 테스트 `finance-store.test.mjs`가 "마지막 마이그레이션 = 재무"라고 가정하던 것을 0003을 이름으로 찾도록 고쳤습니다.

## DB 마이그레이션

필요합니다(0004). 운영 D1 백업 후 사용자가 `npm run db:migrate:cloudflare`를 적용한 뒤 main에 반영합니다.

검증: 타입 검사, 테스트 102개, ESLint, Prettier, Cloudflare 빌드 통과. 로컬 D1에 0004를 적용하고 글 작성·1분 제한·링크 차단·운영자 비밀번호 오류/확인·답글·삭제, 사이트 키가 없을 때 헥사 검색 503 안내를 확인했습니다. 실제 사이트 키로 닉네임 검색은 아직 확인하지 못했습니다.
