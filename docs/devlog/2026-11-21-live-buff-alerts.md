# 2026-11-21 재획 타이머: 버프·부스터·룬 화면 알림

작성: Claude

사용자 피드백을 반영해 재획 타이머를 화면 공유 중심으로 바꿨습니다.

## 바뀐 점

- **재획 시작 = 화면 공유 시작:** 재획 시작 버튼을 누르면 같은 클릭에서 화면 공유 창이 열립니다. 끝내기·취소하면 공유도 멈춥니다.
- **수동 버프 타이머 삭제:** "재획비 30분"처럼 시간을 직접 넣는 타이머를 없앴습니다. 예전 저장값의 타이머는 읽을 때 버립니다.
- **버프 알림:** 게임 버프 아이콘의 남은 시간 숫자(분: 아래쪽 흰 글자, 1분 아래: 가운데 노란 초)가 5초 남았을 때 사라지는 것을 감지해 알립니다. 버프는 모두 30분이라 하나만 등록하면 됩니다.
  - 등록: 버프 아이콘 줄 → 아이콘 하나 → 남은 시간 숫자 칸.
  - 숫자: 밝은 흰색·노란색 픽셀 옆에 검은 테두리가 있으면 글자로 셉니다. 아이콘 그림 속 같은 모양(등록 때 숫자 칸 밖의 글자 픽셀)과 아이콘 바깥 배경은 뺍니다.
  - 아이콘 비교: 숫자가 아이콘 일부를 덮어도 알아보도록 가장 많이 다른 픽셀 40%는 빼고 점수를 냅니다.
  - 숫자 없이 아이콘째 사라지면 "꺼졌어요"로 한 번 알리고, 다시 숫자가 보이면(재사용) 다음 알림을 준비합니다.
- **부스터 알림:** 화면 위 "남은시간" 칸의 시계 아이콘·글자를 등록하면 칸이 2초 이상 사라질 때 알립니다. 어두운 칸이라 배경과 헷갈리지 않도록 픽셀을 빼지 않고 전부 비교합니다.
- **룬 알림:** 미니맵 영역과 룬 표시를 등록하면 나타날 때 알립니다(60초 쿨다운). 실제 룬 화면은 사용자 샘플로 확인할 예정입니다.
- 감지는 0.5초마다 합니다. 판정은 시간 기준으로 다듬습니다(아이콘 0.4초 보임/2초 안 보임, 숫자 1초 보임/0.6초 안 보임).
- 재획 타이머는 PC 전용으로 만듭니다(사용자 요청).

## 고친 문제

- 감지 루프와 등록 화면이 동시에 `ImageCapture.grabFrame()`을 부르면 한쪽이 응답하지 않아 감지가 멈췄습니다. 프레임은 한 번에 하나만 받고, 1초 안에 안 오면 영상에서 그립니다.
- 화면 공유 지원 여부를 렌더 중에 확인해 React 하이드레이션 오류(#418)가 났습니다. 화면이 뜬 뒤 확인하도록 바꿨습니다.

## DB 마이그레이션

필요 없습니다.

검증: 타입 검사, ESLint, 테스트 114개, Cloudflare 빌드 통과. 로컬 서버에서 가짜 게임 화면(캔버스 스트림)으로 재획 시작 시 공유 시작, 버프 등록 3단계(글자 픽셀 34개), 분→초 전환 중 알림 없음, 숫자 사라짐 → "곧 끝나요" 1회, 이어서 아이콘 사라짐 → 추가 알림 없음, 재사용 후 다시 감지, 부스터 등록과 종료 알림(보임 100%/끝남 75%), 분석 2~4ms, 새 탭에서 하이드레이션 오류 없음을 확인했습니다. **실제 게임 화면에서의 정확도는 아직 확인하지 못했습니다.**
