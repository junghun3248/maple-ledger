# 2026-11-22 스타포스 기대 비용 계산기

작성: Claude

## 내용

- 새 화면 `/starforce`(메뉴 "스타포스")를 추가했습니다. 장비 레벨·지금 별·목표 별과 강화 조건을 고르면 목표까지 드는 평균 메소, 평균 파괴 횟수, 필요한 같은 장비(노작) 개수, 평균 시도 횟수를 보여 줍니다.
- 조건: 스타캐치(성공 1.05배), MVP·PC방 할인(17성 미만), 썬데이 비용 30% 할인, 썬데이 파괴 30% 감소(21성까지), 15~17성 파괴 방지(기본 비용 200% 추가, 할인 없음), 파괴 시 "흔적으로 파괴 직전 별까지 복구(최대 22성)" 또는 "같은 장비 1개로 12성부터".
- 결과를 헥사 계산기처럼 기록장 목표 금액으로 바로 등록할 수 있습니다.
- 다른 학생의 졸업작품(넥슨 Open API 기반 전투력·강화 비용 분석) 포스터를 보고 사용자와 이야기해, 가계부 방향에 맞는 "목표 강화 기대 비용"만 가져왔습니다. 전투력 계산과 강화 순서 추천은 직업별 공식 유지 부담이 커서 넣지 않았습니다.

## 계산

- 확률: 2025년 3월 개편(실패해도 별이 내려가지 않음, 최대 30성) 기준. 스타캐치 없는 성공·파괴 확률을 두고 스타캐치는 성공 1.05배, 나머지는 실패·파괴가 원래 비율대로 나눕니다(공개 확률표의 스타캐치 값과 일치를 테스트).
- 1회 비용: 수입·목표의 강화 비용 기록과 같은 `starBaseCost`와 할인 규칙을 씁니다.
- 파괴 복구 메소: 공개된 140·160·200·250제 복구 표가 레벨³에 비례해서, 200제 값을 레벨에 맞춰 환산합니다(140제·250제 표 값과 일치를 테스트). 같은 장비 개수는 15~18성 1개, 19~20성 2개, 21성 3개, 22성 4개.
- 기댓값: 하락이 없으므로 k성 → k+1성 평균 비용 = (1회 비용 + 파괴 확률 × (복구 비용 + 파괴 뒤 k성까지 다시 오르는 비용)) ÷ 성공 확률. 파괴 횟수·장비 개수·시도 횟수도 같은 식으로 구합니다.
- 운: 2,000번 직접 굴려 중앙값과 운 나쁜 10%(90번째 백분위)를 보여 줍니다. 평균 시도 횟수가 너무 많은 목표(예: 29→30성)는 화면이 멈추지 않도록 생략합니다.

## 그 밖에

- 메뉴가 6개가 되어 761~860px 폭에서 오른쪽 버튼이 화면 밖으로 밀렸습니다. 메뉴 접기 기준을 760px에서 860px로 올렸습니다.

## DB 마이그레이션

필요 없습니다.

검증: 타입 검사, ESLint, 테스트 135개(스타포스 8개 추가: 확률·복구 표 일치, 단계 공식, 4,000번 시뮬레이션 평균과 6% 안 일치), Cloudflare 빌드 통과. 개발 서버에서 200제 17→22성 평균 305억·파괴 2.52회, 같은 장비 10억 입력 시 4.99개×10억만큼 늘어남, 12성 복귀 방식 전환, 780·870·1000·1280px 폭에서 가로 넘침 없음을 확인했습니다.

## 추가: 다른 계산기 사이트를 참고한 개편

사용자가 다른 스타포스 계산기 사이트(starforce.gg)를 참고해 달라고 해, 디자인·아이콘은 가져오지 않고 기능 구성만 참고했습니다.

- 장비 빠른 선택: 140~250제 대표 장비 이름 버튼(레벨만 정함).
- 이벤트: 노이벤 / 30% 할인 / 30% 파괴 감소 / 샤타(비용 30% 할인 + 21성 이하 파괴 30% 감소 + 복구 비용 20% 할인) / 샤타 + 15·16성 100%.
- 파괴 방지를 15·16·17성마다 따로 고름.
- 확정 복구: 파괴되면 12성(같은 장비만) 또는 15~22성 중 고른 별까지 복구(파괴 직전 별보다 높게는 못 함). 공개된 복구 표가 단계별로 있어 낮은 별로 복구하는 경우도 계산합니다.
- 강화 최적화: 별마다 파괴 방지 여부와 복구할 별을 평균 비용이 가장 적은 쪽으로 고릅니다. k성의 선택은 k성 단계 비용에만 들어가고 뒤 단계에는 그 비용이 더해지기만 하므로, 별마다 가장 싼 선택이 전체에서도 가장 쌉니다.
- 결과: 시작 별 버튼, 각 목표 별까지의 누적 기대값·평균 파괴·평균 시도 표(단계별 보기 전환), 메소/원 단위(1억 메소당 원 입력), 엑셀 복사. 표의 줄을 누르면 그 별이 목표가 됩니다.

### 참고 사이트와 숫자 비교

같은 조건(200제, 샤타, 15~17성 파괴 방지, 확정 복구 18성, 노작 190억)에서 12→22성 평균 685억(참고 사이트 696억), 평균 파괴 2.43회(2.44회), 12→25성 50.88회(51.09회)로 파괴 횟수는 거의 같고 금액은 약 2% 안입니다.

- 12~14성 1회 비용은 우리 쪽이 약 1.43배 높습니다. 우리는 강화 비용 기록과 같은 식(Codex 정리, "2026-10-22 개편 이후")을 쓰고 참고 사이트는 이전 공식과 같습니다. 어느 쪽이 지금 게임과 맞는지 사용자 확인이 필요합니다.
- 평균 시도 횟수는 참고 사이트가 더 크게 나옵니다(세는 방식 차이로 보이며 확인하지 못했습니다).

검증: 타입 검사, ESLint, 테스트 138개(이벤트·별별 파괴 방지·확정 복구·누적 표·최적화가 고정 선택보다 비싸지 않음 추가), Cloudflare 빌드 통과. 개발 서버에서 위 조건으로 표·최적화 선택(19~23성 18성 복구)을 확인했습니다.
