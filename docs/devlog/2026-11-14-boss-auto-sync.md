# 2026-11-14 보스 클리어 자동 동기화

작성: Claude

보스 페이지를 열거나 새로고침하면 등록한 캐릭터의 이번 주기 클리어 상태를 넥슨 스케줄러 API로 다시 확인합니다. 닉네임이나 API 키를 다시 입력하지 않습니다.

## 문제

클리어 상태는 API 가져오기 창에서 다시 가져와야만 갱신됐습니다. 다시 가져오면 기존 값을 그대로 덮어썼고, 직접 클리어를 체크하는 방법은 없었습니다.

## 동작

- 기존에 저장하던 캐릭터 식별값(`nexonId`)과 이 브라우저에 저장된 API 키로 재조회합니다.
- 페이지를 열 때 자동 조회하되 같은 기록장은 10분 안에 다시 호출하지 않습니다. 동기화 줄의 `새로고침`은 바로 조회합니다. 자동 조회는 캐릭터 이미지 요청을 생략해 넥슨 호출 수를 절반으로 줄입니다.
- 이번 주기에 기록이 있으면 같은 보스·난이도의 클리어 여부만 바꿉니다. 인원, 물욕템, 판매가, 결정석 가격은 유지합니다.
- 이번 주기 기록이 하나도 없으면(새 주) 스케줄러에 등록된 보스를 지난 기록의 인원과 함께 추가합니다. 사용자가 구성한 주에는 보스를 더하지 않습니다.
- 조회에 실패한 캐릭터는 아무것도 바꾸지 않고 실패로만 표시합니다. 모두 실패하면 마지막 동기화 시각도 바꾸지 않습니다.
- 기록장이 열려 있고 저장하지 않은 변경이 없을 때만 동기화 결과를 서버에 자동 저장합니다. 그 외에는 기존처럼 이 기기에 임시 저장합니다.

## 우선순위

`직접 설정 > 넥슨 API > 기본값`입니다. 보스 상세에 `클리어` 체크를 추가했고, 직접 바꾼 기록은 `clearedBy: "manual"`로 표시해 자동 동기화와 다시 가져오기가 바꾸지 않습니다. `자동으로 되돌리기`로 해제할 수 있습니다. API가 반영한 값은 `clearedBy: "api"`입니다.

파티 처치 시 파티장이 아닌 캐릭터의 완료 표시가 갱신되지 않는다는 커뮤니티 보고가 있어, 이런 경우 직접 체크하면 됩니다.

## 넥슨 API 범위

넥슨 공지 기준으로 스케줄러 API는 실시간 조회와 최대 14일 전까지의 조회를 지원합니다. 보스 정보는 해당 콘텐츠를 완료할 때 갱신되며, 2026-06-25 이후 접속한 캐릭터만 조회됩니다. 게임 스케줄러에 등록하지 않은 보스와 가격표에 없는 보스는 자동으로 추정하지 않습니다. 호출 한도는 키 단계별로 달라 공식 수치를 확인하지 못했으며, 기존 300ms 간격 호출과 429 재시도를 유지합니다.

## 데이터

`boss_plans` JSON의 각 보스 기록에 선택 필드 `clearedBy`만 추가했습니다. DB 마이그레이션은 없고, 필드가 없는 기존 기록은 그대로 읽고 저장됩니다.

## 검증

- 자동 테스트 90개 통과(신규 10개: API 반영, 수동 우선, 실패 시 보존, 새 주 추가, 편집한 주 보존, 호출 간격, 기존 데이터 호환).
- TypeScript 통과, ESLint 신규 경고 없음, Cloudflare 빌드 통과.
- 로컬 Worker + D1 통합 테스트 통과.
- 브라우저에서 API 응답을 모의해 확인: 자동 조회 1회, 10분 내 재방문 시 재호출 없음, 새로고침 시 재호출, 직접 설정한 보스는 유지.
- 기록장 서버 저장 확인: API 실패 시 서버 기록 변경 없음, 성공 시 클리어만 바뀌고 인원·물욕템·지난 주 기록·프리셋 유지.
