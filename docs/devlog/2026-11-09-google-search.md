# 구글 검색 등록 준비

- 사용자 제공 HTML 소유권 확인 파일을 루트 주소에서 제공합니다.
- 홈페이지 제목에 메소저장소와 서비스 용도를 표시하고 공통 검색 설명을 추가했습니다.
- 세 공개 페이지에 대표 주소를 설정하고 robots.txt 및 sitemap.xml을 제공합니다.
- 개인 기록과 API 응답은 사이트맵에 포함하지 않습니다.
- Search Console 소유권 확인을 완료하고 홈페이지 색인 생성 요청이 접수되었습니다. 사이트맵도 제출했습니다.
- 실제 검색 노출 시기와 순위는 Google이 결정하며 등록만으로 보장되지 않습니다.

## 검증

타입 검사, 변경 파일 ESLint, Cloudflare 빌드 및 배포를 완료했습니다. 확인 파일·robots.txt·sitemap.xml은 HTTP 200이며 홈페이지 제목과 대표 주소도 실제 응답에서 확인했습니다.

사이트맵은 Google에서 읽기 오류를 표시해 재제출했습니다. HTTP 응답과 XML은 정상이지만 Google의 처리 성공은 아직 확인하지 못했습니다.
