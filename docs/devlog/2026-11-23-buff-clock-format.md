# 2026-11-23 재획 타이머: 버프를 "분+초" 표시로 읽기

작성: Claude

## 내용

- 게임 UI 기본 설정은 버프 아이콘 아래에 분만 보여 주고 1분 아래로 내려가면 노란 초 숫자로 바뀌어, 분 숫자 자리만 등록하면 초로 넘어갈 때 읽지 못했습니다(사용자 확인). UI 설정에서 버프 남은 시간 표시를 "분+초"로 바꾸면 아이콘 가운데에 `2:37`처럼 뜨므로, 새로 등록하는 버프는 야누스처럼 이 시간 전체를 감싸 등록하고 통째로 읽게 바꿨습니다.
- 버프 등록 3단계에서 고른 칸을 바로 읽어 "읽은 시간 2:37 (157초)"처럼 보여 줍니다.
- 사용 안내 창과 버프 등록 안내에 "버프 남은 시간 표시를 분+초로 바꿔 주세요"를 넣었습니다. 안내 내용이 바뀌어 "다시 보지 않기"를 눌렀던 사람에게도 한 번 더 뜹니다.
- 예전 방식(분만 표시)으로 등록한 버프는 그대로 동작하고, 상태 줄에 "분+초로 바꾸고 다시 등록해 주세요"를 보여 줍니다.
