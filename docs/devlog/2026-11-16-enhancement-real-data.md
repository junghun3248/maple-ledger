# 2026-11-16 강화 비용: 실제 이력 형식 대응과 진행 막대

작성: Claude

실제 API 키로 불러온 강화 이력 373건이 모두 `계산에서 빠짐`으로 나와 비용이 0으로 표시되던 문제를 고쳤습니다. 넥슨 문서에는 필드 이름만 있고 값 예시가 없어, 처음 구현이 예상한 문구와 실제 문구가 달랐던 것으로 보입니다.

- 조건 값(슈페리얼, 파괴 방지, 프로텍트 실드, 주문서)을 `미적용·미사용·미해당·아님·없음` 등 부정형과 `적용·사용` 등 긍정형으로 넓게 판별합니다. 모르는 형식만 제외합니다.
- `잠재능력 재설정`, `에디셔널 잠재능력 재설정`처럼 이름이 달라도 잠재능력 재설정으로 인식합니다. 결과 옵션이 2~3줄이어도 1회로 계산합니다.
- 비용과 무관한 `파괴 방지 필드 이벤트`, 찬스 타임, 스타캐치는 더 이상 제외 사유가 아닙니다.
- 이벤트 범위 `0~22성`, `10-22`, `전체` 형식과 `30 %` 같은 할인율 표기를 받습니다.
- 계산에서 빠진 이력을 이유별로 묶고, 넥슨이 돌려준 값을 함께 보여 줍니다(예: `파괴 방지: ○○`). 남은 형식 문제를 바로 찾을 수 있습니다.
- 이력을 불러오는 동안 날짜·종류별 진행 막대와 찾은 건수를 보여 줍니다(사용자 요청).

검증: 타입 검사, 테스트 89개(실제 문구 형식·제외 사유 표시 테스트 추가), ESLint, Cloudflare 빌드 통과. 실제 키로 다시 불러와 금액이 맞는지는 사용자 확인이 필요합니다.
