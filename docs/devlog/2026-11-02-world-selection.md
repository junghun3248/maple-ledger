# 스케줄러 캐릭터 조회에 월드 선택 추가

## 변경

기존에는 계정 캐릭터 목록을 받은 직후 모든 월드 캐릭터의 전투력을 조회했다.
이제 목록 1회 조회로 보유 월드를 표시하고, 사용자가 월드를 선택한 후 해당 월드에만 전투력 상세 조회를 보낸다.

- 월드별 캐릭터 수 표시 및 마지막 선택 월드 기억
- 전투력 1,000만 초과 필터와 여러 캐릭터 선택 유지
- 월드·API 키 변경 시 이전 선택과 보스 미리보기 초기화
- 창을 닫은 뒤 도착한 응답은 반영하지 않음
- 전체 캐릭터 기본 목록 조회 1회는 월드 파악에 필요하지만, 다른 월드의 개별 전투력 조회는 실행하지 않음

## 검증

월드별 요청 분리, 8명 배치, 전투력 경계값, 취소 시 후속 요청 중단 테스트를 추가했다.
시뮬레이터 미완성 작업은 별도 보관했으며 이번 변경에는 포함하지 않는다.
