# 2026-11-03 강화 시뮬레이터

- 잠재능력·에디셔널·스타포스 메뉴를 추가했다.
- 닉네임 장비 조회와 수동 부위·레벨 선택을 제공한다.
- 잠재 재설정의 전후 선택, 목표까지 자동 실행, 예산 제한과 비용 이력을 추가했다.
- 스타포스 목표 강화, 파괴·복구, 이벤트·할인과 추정 비용을 연결했다.
- 기존 사냥·보스 기록과 분리해 가상 결과만 계산한다.

범위 및 계산 근거는 [시뮬레이터 문서](../simulator.md)를 참고한다.

브라우저에서 공식 에디 확률 조회, 결과 선택, 목표 강화, 파괴 및 12성 복구 비용 합산을 확인했다. 실제 개인 키로 장비 조회하는 검증은 수행하지 않았으며 API 응답 매핑은 모의 응답으로 검사한다.
