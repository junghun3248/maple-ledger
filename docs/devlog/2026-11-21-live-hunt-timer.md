# 2026-11-21 재획 타이머 (실시간 사냥 도우미 1단계)

작성: Claude

## 내용

- 새 화면 `/hunting/live`(재획 타이머)를 추가하고 사냥 기록 화면 머리글에 링크를 달았습니다. 메뉴 개수는 그대로입니다.
- 재획 세션: 시작·일시정지·다시 시작·취소·끝내고 기록하기. 일시정지한 시간은 빼고 셉니다. 진행 중에는 탭 제목에 경과 시간을 보여 줍니다.
- 끝내고 기록하면 사냥 기록 입력칸에 날짜(시작한 날)와 사냥 시간(분)을 채웁니다. 메소·조각은 기존처럼 사진으로 읽어 확인한 뒤 저장합니다. 세션 자체는 따로 저장하지 않아 기록이 중복되지 않습니다.
- 버프 타이머: 이름·시간·반복을 정해 최대 12개. "재획비 30분" 빠른 추가 버튼.
- 알림: Web Audio 알림음(소리 파일 없음, 켜기/끄기·볼륨), 사용자가 허락하면 브라우저 알림.

## 구현 메모

- 모든 시간은 절대 시각(ms)으로 `localStorage`(`maple-hunt-live-v1`)에 저장합니다. 새로고침·탭 전환에도 남은 시간이 맞습니다. 저장값은 Zod로 검사하고 깨지면 기본값으로 돌아갑니다.
- 각 주기는 한 번만 알립니다(`alerted`). 창을 닫아 둔 사이 끝난 주기는 소리 없이 화면에만 표시합니다(1분 기준).
- 뒤로 간 탭에서 타이머가 늦어지지 않도록 Blob Worker로 1초마다 깨웁니다. Worker를 못 만들면 일반 `setInterval`을 씁니다.
- 화면 공유·이미지 감지는 아직 없습니다(2단계). 서버·DB는 바꾸지 않았습니다.

## 파일

- `app/hunting/live/page.tsx`, `app/sitemap.ts`
