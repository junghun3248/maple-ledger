# 촬영 안내, 첫 보스 등록, 방문자 집계

작업 시작 시 로컬 브랜치는 refactor/architecture-2026-10-31이었으며 GitHub 열린 PR은
없었습니다. main에도 새 Manus 변경이 없어 기존 구현에 이어서 작업했습니다.
이전에 준비한 넥슨 API 호출 간격·429 재시도 수정도 함께 포함합니다.

## 사냥 촬영

- 사진 업로드 위에 촬영 지침과 촬영 예시 보기 버튼 추가
- 첨부 이미지에서 인벤토리만 잘라 예시 사용, 첫 칸의 178개와 메소 잔액 강조
- 다시 보지 않기는 브라우저 localStorage에 저장, 예시 버튼으로 재열기 가능
- 조각 탐색 범위를 첫 열에서 인벤토리 영역으로 확대
- 여러 조각 칸은 중복 제거 후 각각 확대 표시, 교불·교가는 판정하지 않음
- 여러 묶음일 때 한쪽만 자동 입력하지 않도록 합계는 직접 확인·입력

## 보스 등록

등록 캐릭터가 없는 화면에서는 스케줄러 API 추가를 주 버튼으로 제공하고
캐릭터 선택·닉네임 추가는 다른 방법으로 추가 안에 배치합니다.
기존 캐릭터가 있으면 관리 버튼은 유지합니다.

## 방문자

공통 헤더에 오늘 방문자 수를 표시합니다. 한국 시간 자정 기준이며 브라우저의
무작위 식별자를 날짜와 함께 해시하여 D1에서 하루 중복을 차단합니다.
고유 키와 INSERT 트리거로 동시 요청도 한 번만 증가합니다. 7일이 지난 중복 방지
토큰은 정리하고 일별 합계만 남깁니다. 계정·IP·API 키와 연결하지 않습니다.
저장소를 지우거나 다른 브라우저·시크릿 창을 사용하면 별도 방문으로 집계되므로
실제 사람 수가 아닌 브라우저 기준 지표입니다. 저장소 차단 또는 API 장애 시
0명으로 오인하지 않도록 대시로 표시합니다.

0002_daily-visitors 마이그레이션과 Cloudflare 배포를 완료했습니다.
트리거는 SQL 마이그레이션으로 관리하며 Drizzle 스키마에 별도 선언하지 않습니다.

## 검증

타입 검사, 전체 회귀 테스트, SQLite 동시·중복·자정 집계, 두 조각 칸 합성 이미지
탐지, 실제 첨부 이미지 두 위치 탐지, Cloudflare 빌드를 통과했습니다. 전체 테스트 65개가 통과했습니다.
