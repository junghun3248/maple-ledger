# 2026-10-31 · 리팩토링 준비와 서버 분리

Prettier 및 프로젝트 작업 규칙을 설정하고 원본 보존·별도 리팩토링 브랜치를 만들었습니다. 현재 구조, 목표, 명세, 아키텍처, 로드맵을 먼저 문서화했습니다.

서버 구현을 server/ledger로 추출하고 HTTP 진입점과 기존 내부 경로 호환성을 유지했습니다. 사냥 기록 계약은 contracts로 분리하고 DB 행 타입과 구분했습니다. 타입 검사와 변경 영역 ESLint, 자동 테스트를 통과했습니다.

React UI 이전과 레거시 삭제는 아직 완료되지 않았으며 운영 배포는 하지 않았습니다. 상세 진행 상태는 [검증 현황](../refactoring/validation.md)을 참고하세요.
