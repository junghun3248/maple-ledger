# 2026-10-31 · 저장소 구조와 React 화면 전환

Prettier 및 AGENTS 규칙을 적용하고 원본 보존 브랜치에서 기능 단위로 구조를 정리했다. 사냥·보스 화면을 Next.js App Router와 React로 연결하고, 기존 public HTML·DOM 스크립트를 대체했다.

캐릭터·드롭·보스 구성·스케줄러·캘린더·OCR 연결을 기능별 컴포넌트로 분리했다. 공유 계약은 Zod 기반으로 정리하고, 계정·인증·요청 제한·저장 책임을 server로 분리했다. 기존 DB와 revision 기반 충돌 방지는 유지한다.

DB 테이블·마이그레이션·저장 규칙을 문서화하고 실제 SQL과 Drizzle 선언을 비교하는 검사를 추가했다. 자동 테스트 33개, 타입·포맷·빌드 및 두 세션 HTTP 통합 검사를 통과했다. [검증 범위와 한계](../refactoring/validation.md)를 참고한다.

원본 백업 브랜치는 유지한다. API 키와 사용자 기록은 공개 저장소에 포함하지 않는다.
