# 2026-11-07 메소저장소 독립 호스팅

사이트 표시 이름을 메소저장소로 변경하고, 개인 Cloudflare 계정의 Workers와
D1에 독립 배포했습니다. ChatGPT 계정 없이 기존 기록장 방식으로 사용할 수 있습니다.

- 주소: https://maple-ledger.meso-sg.workers.dev
- 사냥·보스·수입 추이 화면과 동일 출처 API를 유지합니다.
- 독립 빌드는 Sites 인증·커넥터 및 실제 Sites 메타데이터를 요구하지 않습니다.
- 배포 전 Worker 이름과 DB 바인딩을 확인하여 다른 호스팅 빌드를 차단합니다.
- 칠흑 상자 아이콘을 포함한 보스 기록의 저장 검증도 수정했습니다.
- 기존 Sites 사이트와 데이터는 유지하며 자동으로 복제하지 않았습니다.

## 검증

- TypeScript 통과
- ESLint: 기존 Navigation의 일반 앵커 링크 규칙 오류 1건 확인 (기존 탐색 동작 유지)
- 회귀 테스트 58개 통과
- Cloudflare 빌드와 배포 성공
- 새 주소에서 사냥·보스·수입 화면 응답 및 브랜드 표시 확인
- 테스트 기록장 생성, 사냥·보스 저장, 로그아웃·재로그인 후 복원 확인
- 미인증 접근 거부와 오래된 수정 버전의 충돌 응답 확인
- 테스트 기록장과 해당 보스 데이터 정리 완료

실제 넥슨 키를 이용한 스케줄러 재조회 및 기존 사용자 데이터 이전은 이번
검증에 포함하지 않았습니다. 키는 새 주소에서 다시 입력해야 합니다.
