# 2026-11-21 재획 타이머 화면 공유 감지 (2단계)

작성: Claude

## 내용

- 재획 타이머에 "화면 공유 감지" 칸을 추가했습니다. 사용자가 버튼을 눌러야만 공유가 시작되고, 공유 중 표시·중지 버튼이 있으며 브라우저에서 공유를 끊어도 바로 정리됩니다.
- **메소·조각 스냅샷:** 공유 화면 한 장을 기존 사진 인식 엔진(`features/hunting/ocr`)에 그대로 넣어 사냥 전·후 메소와 솔 에르다 조각을 읽습니다. 끝내고 기록하면 사냥 기록 입력칸에 날짜·시간과 함께 채워지고, 저장 전 확인은 기존대로 사용자가 합니다.
- **감지 등록:** 룬·버프 색이나 모양을 미리 넣지 않고, 사용자가 멈춘 자기 화면에서 ① 살펴볼 영역(최대 480×480px) ② 알아볼 아이콘(6~64px)을 드래그해 등록합니다. "나타나면 알림"(룬)과 "사라지면 알림"(버프 꺼짐)을 고를 수 있고 최대 8개, 민감도 3단계입니다.
- 참고 사이트·넥슨 이미지나 모델은 쓰지 않았습니다. 입력 자동화·메모리 읽기·패킷 캡처는 없습니다.

## 구현 메모

- 1초마다 등록한 영역만 잘라 RGB 차이로 아이콘을 찾습니다(`detectors/template.ts`). 큰 아이콘은 표본 픽셀을 듬성듬성 비교해 최악의 경우(480×480 영역, 64px 아이콘)도 약 130ms, 미니맵 크기(220×160, 12px)는 약 10ms입니다.
- 판정이 흔들려도 깜빡이지 않도록 2프레임 연속이면 "보임", 3프레임 연속이면 "안 보임"으로 바꾸고, 같은 알림은 60초 쿨다운을 둡니다(`detectors/state.ts`).
- 프레임은 메모리 캔버스에만 그리고 저장·전송하지 않습니다. 등록한 아이콘 조각과 영역 좌표만 이 브라우저의 `localStorage`에 남습니다. 화면 크기가 바뀌면 다시 등록하라고 안내합니다.
- Chrome·Edge에서는 `ImageCapture.grabFrame()`으로 트랙에서 직접 프레임을 받아 탭이 가려져도 분석이 이어집니다. 없으면 `<video>`에서 그립니다.
- 예전 저장값(감지 항목 없음)도 그대로 읽히도록 새 항목에 기본값을 두었습니다. 서버·DB는 바꾸지 않았습니다.
