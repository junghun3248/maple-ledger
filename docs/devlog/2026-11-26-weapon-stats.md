# 해방 무기 통계

작성: Codex

- `/weapon-stats`에 전체 해방률과 직업별 에공삼·에마삼 비율을 추가했다. 해방률은 해방 여부를 확인한 종합 랭킹 캐릭터를, 에디 비율은 해방 제네시스 또는 데스티니 주무기를 확인한 캐릭터를 분모로 쓴다.
- 마법사(레테 포함)는 마력%, 나머지 직업은 공격력%만 유효 옵션으로 집계한다. 제네시스는 같은 공격력% 또는 마력% 12·9·9, 12·12·9, 12·12·12 조합만 센다. 데스티니는 같은 공격력% 또는 마력% 3줄을 센다.
- 넥슨 종합 랭킹의 일반 월드와 에오스·핼리오스를 같은 기준일로 조회한다. 화면에는 조회 범위와 확인 건수를 표시한다. DB 마이그레이션은 필요 없다.

## 집계 방법

서비스용 넥슨 API 키를 실행 환경의 `NEXON_API_KEY`로 설정한 뒤, 이미 발표된 KST 랭킹 날짜를 지정한다.

```sh
npm run stats:weapons -- --date 2026-11-25 --interval-ms 35
```

`--pages 1`을 추가하면 월드 유형마다 첫 페이지만 조회한다. `--min-level 260`을 추가하면 260 이상으로 범위를 제한한다. 둘 다 생략하면 API가 반환하는 전체 랭킹을 조회한다. 개발용 키를 사용할 때는 기본 요청 간격인 250ms를 사용한다.

중단 후 같은 날짜와 최소 레벨로 실행하면 `work/weapon-stats/`에 저장한 완료 페이지를 재사용한다. 완료 후 `public/weapon-stats.json`에는 집계 수치만 생성된다. 화면의 기준일 및 집계 범위를 확인한 뒤 이 파일을 기존 배포 흐름으로 갱신한다.

## 검증

npm 10의 `npm ci`, 타입 검사, 변경 범위 ESLint·Prettier, 테스트 146개, Cloudflare 빌드를 확인했다. 가짜 랭킹 응답으로 두 월드 유형, 장비 판정, 집계 파일 생성과 재실행을 확인했다. 서비스용 키로 실제 첫 전수 집계를 실행해야 한다.
