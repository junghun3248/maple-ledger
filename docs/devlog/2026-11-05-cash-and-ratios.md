# 캐시 상자 개봉과 보스 배율 사진 입력

- 알쏭달쏭 코디 상자의 첨부 시세(만 메소)와 29종 확률을 별도로 관리한다. 1상자는 티켓 5장이며 가격은 이 기기에 저장한다.
- 개봉 결과는 해당 회차의 가격으로 정산하고, 시세를 바꾸면 다음 회차의 기대값을 다시 계산한다. 2% 아이템은 희귀 색상, 10억 메소 이상 획득은 강조 표시한다.
- 보스 페이지에서 캐릭터별로 환산 결과 사진을 읽고 개인 배율을 검토한 뒤 적용한다. 알려진 초상화만 탐색하며 미확인 카드와 파티 배율은 기본 선택에서 제외한다.

- 스케줄러에서 선택한 캐릭터의 기본 정보로 초상화를 채운다. 이미지 조회가 실패하면 기존 사진을 유지한다.
