# 2026-11-06 물욕템 선택 표시

- 미선택 물욕템은 흰색, 선택하면 연두색 배경·초록 테두리·체크 표시로 구분한다.
- 아이콘 불투명도 55% 처리를 제거하고 원본 비율과 크기를 유지한다. 작은 게임 도트 이미지를 정사각형으로 강제 확대하지 않는다.
- 칠흑 상자는 여백이 큰 1254px 이미지 대신 실제 37px 게임 아이콘 원본으로 교체했다. 출처: https://meso.kr/boss-reward/dark_boss_box.png (NEXON 게임 이미지).
- 확인한 대체 아이템 원본도 대부분 30~40px로, 고해상도 그림으로 새로 만든 것은 아니다.
- 선택 상태와 물욕템 수익 계산 방식은 유지한다.
- 검증: 타입 검사, 기존 테스트 및 배포 빌드.
