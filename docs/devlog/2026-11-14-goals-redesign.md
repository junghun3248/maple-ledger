# 2026-11-14 목표 화면 개편

작성: Claude

메이플 다이어리 등 다른 메이플 가계부의 목표 화면을 참고해 목표 탭을 다시 만들었습니다. 저장 데이터 구조(`goals`)는 그대로입니다.

- **나의 다음 목표** 카드: 현재 잔액 → 남은 메소 → 진행률을 한 줄로 보여주고 진행 막대와 예상 기간을 표시합니다. 현황 탭에도 같은 카드를 두었습니다. 잔액을 아직 입력하지 않았으면 값 대신 `—`와 안내를 보여줍니다.
- 목표를 카드 격자로 보여줍니다. 각 카드에 금액, 진행 막대, 남은 금액을 표시하고 `달성 가능`·`일시정지` 표시를 붙였습니다. `완료`, `수정`, 더보기(위로·아래로·일시정지·삭제) 버튼이 있습니다.
- 목표 만들기와 수정은 브라우저 `prompt` 대신 대화상자에서 합니다. `+1억`·`+10억`·`+100억` 빠른 입력이 있습니다.
- 완료한 목표는 접힌 목록으로 따로 모았고 되돌릴 수 있습니다.
- 예상 기간은 기존 계산(최근 28일 중 14일 이상 기록, 순수익 양수)을 그대로 쓰며 조건이 안 되면 추정하지 않습니다.
- `GoalsPanel.tsx`, `AmountHint.tsx`로 분리해 `AssetPage.tsx`가 760줄에서 580줄로 줄었습니다. 대화상자 기본 스타일을 공통 테마에 추가했습니다.

검증: 테스트 79개(진행률 계산 테스트 추가)·타입 검사·Cloudflare 빌드 통과. 로컬 기록장에서 목표 4개(진행 중, 달성 가능, 일시정지, 완료)로 PC/모바일 × 라이트/다크 화면을 확인했고, 대화상자로 만든 목표가 서버에 저장되는 것과 보스·사냥 대화상자가 그대로인 것을 확인했습니다.
