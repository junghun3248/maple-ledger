# 2026-10-30 — API 키 재사용과 기록장 입력 제한

- 캐릭터 조회에 성공한 넥슨 API 키를 해당 브라우저의 로컬 저장소에 보관한다. 다음 캐릭터 추가 시 자동 조회하며, 키 삭제·변경 버튼을 제공한다.
- 서버 DB, 기록장 백업과 GitHub에는 키를 저장하지 않는다. 다른 기기에서는 별도로 키를 입력한다.
- 기록장 이름의 3~40자 제한을 제거한다. 빈 이름과 제어 문자는 허용하지 않으며 일반 요청 용량 제한은 유지한다.
- 새 기록장 비밀번호는 9~128자로 설정한다. 기존 기록장의 이름 정규화와 암호 검증 방식은 유지한다.
- 사냥 계산과 OCR은 변경하지 않고 공통 기록장 입력창만 조정했다.

검증: 관련 17개 테스트와 빌드 통과. 브라우저에서 키 재입력 없는 자동 조회·키 삭제를 확인했다. 로컬 API에서 99자 이름과 9자 비밀번호로 생성 및 재로그인에 성공했다.
