# 2026-11-14 보스 자동 저장과 화면 다듬기

작성: Claude

## 보스 자동 저장

기록장이 열려 있으면 보스 화면의 변경을 1.2초 뒤 서버에 자동 저장합니다. 연속으로 바꾸면 마지막 변경 후 한 번만 저장합니다. 저장 중에 또 바뀌면 끝난 뒤 다시 저장하고, 실패하면 오류를 표시하며 이 기기의 임시 저장은 유지합니다. 클리어 자동 동기화 결과도 같은 방식으로 저장됩니다. `저장` 버튼은 즉시 저장용으로 남겼습니다.

## 상태 문구

긴 안내 문장을 `저장 중…`, `저장됨`, `이 기기에만 저장됨`, `저장 안 된 변경을 복원했어요` 같은 짧은 상태로 바꿨습니다.

## 제보 버튼

화면 오른쪽 아래에 떠서 버튼을 가리던 `건의·버그 제보`를 상단 바의 `제보` 버튼으로 옮겼습니다. 링크는 같습니다.

## 주간 표기

보스 화면의 주간 범위를 `2026-11-12 ~ 2026-11-18`에서 `11.12(목) ~ 11.18(수)`로 표시합니다.

## 배포

배포에 Cloudflare API 토큰만 필수로 바꿨습니다. 계정 ID 시크릿이 없으면 wrangler가 토큰으로 접근 가능한 계정을 사용합니다.
