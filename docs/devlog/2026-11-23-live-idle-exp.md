# 2026-11-23 재획 타이머: 동꼽 방지(경험치 바 알림)

작성: Claude

## 내용

- 재획 타이머에 "동꼽 방지"를 넣었습니다. 등록 없이 화면 맨 아래 경험치 바 가운데 숫자를 읽어, 재획 중(일시정지 아님)에 숫자가 10초 넘게 그대로면 "캐릭터 움직이세요"라고 말합니다. 계속 멈춰 있으면 30초마다 다시 알리고, 숫자가 오르면 다시 셉니다. 켜기·끄기만 있고 기본은 켜짐입니다.
- 경험치 바는 해상도와 관계없이 같은 크기로 게임 화면 맨 아래에 있다는 사용자 설명에 맞춰, 화면 아래쪽(최대 200px) 가운데 40% 폭에서 흰 글자 줄(4~14px 높이)을 찾고 그중 가장 아래 것을 경험치 숫자로 봅니다. 위쪽 HP·MP 바 숫자와 겹치지 않고, 왼쪽이 채팅창에 가려져도 됩니다. 위치는 10초마다 다시 찾습니다.
- 0.5초마다 그 숫자 칸만 잘라 지난 화면과 비교해, 채널 차이 40이 넘는 픽셀이 3개 이상이면 오른 것으로 봅니다. 숫자를 읽지 않아 빠르고, 게임 글꼴과 관계없습니다.
- 음성 "캐릭터 움직이세요"는 기존 대사와 같은 Supertone Supertonic 3 F1 목소리·설정으로 로컬에서 만들었습니다(`public/voice/idle.wav`, 1.1초, 작업 PC `E:\Codex\voice-work\scripts\generate_idle.py`).

- `features/hunting/live/ScreenWatch.tsx`: 감지 루프와 "동꼽 방지" 줄(오르는 중 / N초째 그대로 / 못 찾음 / 재획 중에만)
