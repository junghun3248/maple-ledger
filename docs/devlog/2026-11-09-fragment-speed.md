# 조각 위치 탐색 속도 개선

메소 판독 전에 전체 인벤토리의 여러 크기를 비교하던 조각 탐지가 지연을 만들었습니다.
조각의 파란 중심색을 먼저 검사해 후보가 아닌 위치의 정밀 비교를 건너뜁니다.
메소 판독 및 한 칸 조각의 기존 숫자 판독 로직은 유지했습니다.
여러 칸은 별도로 확대 표시하고 교환 가능 여부는 추측하지 않습니다.

첨부 사진 세 장의 위치 탐색 비교에서 결과는 같았으며 2325/2679/2692ms에서
74/61/52ms로 감소했습니다. 개발 환경에서 측정한 위치 탐색 시간이며 전체 OCR
처리 시간이나 모든 기기의 속도를 의미하지 않습니다.
빈 인벤토리·한 칸·두 칸의 회귀 테스트를 포함합니다.
