# 2026-11-27 재획 타이머: 야누스도 등록 없이 찾기

작성: Claude

## 내용

- 사용자 요청으로 야누스도 등록 없이 찾습니다. 사용자 게임 화면에서 야누스 아이콘(보라색 구슬)을 32×32로 잘라 넣었습니다(`public/janus.png`).
  - 버프·룬 쿨타임과 같은 방법으로 화면 위쪽 절반에서 찾고, 끝나기 10초 전에 "야누스 꺼져요"라고 알립니다.
  - 아래쪽 스킬 단축키 칸은 보지 않습니다.
  - 켜고 끌 수 있습니다(`autoJanus`, 기본 켜짐).
- 사용자 화면 두 장(밝은 배경·어두운 배경)에서 정확한 자리를 찾았습니다. 점수는 1.0과 0.91입니다.
- 이제 직접 등록할 알림이 없어서 등록 화면을 지웠습니다.
  - 지운 것: `RegionPicker`, 등록 단계, 민감도 선택, 색 비교 찾기(`matchTemplate`, `robustScore`), 관련 CSS·테스트.
  - 예전에 등록한 알림은 버프·야누스·룬 모두 감지하지 않고, 삭제 안내만 보여 줍니다. 안내 창 키는 v6입니다.
