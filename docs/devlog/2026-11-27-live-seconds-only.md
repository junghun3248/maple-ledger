# 2026-11-27 재획 타이머: 1분 아래 초만 보이는 시간도 읽기

작성: Claude

## 내용

- 사용자가 사냥 중일 때 게임 화면을 캡처해서 감지를 그대로 돌려 봤습니다.
  - 아이콘 찾기는 세 개 모두 맞았습니다. 재물 획득의 비약은 82%, 룬 쿨타임은 88%, 야누스는 87%입니다(기준 60%).
  - 노란 시간 글자도 깨끗하게 잘렸습니다("36", "1:08", "20").
- 원인: 1분 아래로 남으면 게임은 "36"처럼 초만 보여 줍니다. 그런데 `parseSeconds`의 `clock` 모양이 "m:ss"만 받아서, 이 값을 잘못 읽은 글자로 보고 버렸습니다.
  - 그래서 1분 아래에서 감지를 시작하거나 그 전에 시간을 못 읽은 경우에는 10초 전 알림이 오지 않았습니다.
- 수정: `clock` 모양도 1~59 사이의 초만 있는 숫자를 받습니다. 잘못 읽은 값은 기존처럼 `track`이 이전 추정과 비교해서 걸러 냅니다.
