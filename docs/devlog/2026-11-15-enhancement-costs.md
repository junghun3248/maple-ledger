# 2026-11-15 강화 비용 반영

작성: Claude (Codex 11-11 작업 이어받음)

넥슨 API 키로 스타포스와 잠재능력·에디셔널 재설정 이력을 읽어 쓴 메소를 계산하고, 메소 기록에서 빼도록 했습니다.

- `/income`에 **강화 비용** 패널을 추가했습니다. 기간(최대 31일)을 골라 이력을 불러오고, 계산 금액을 확인한 뒤 기록에 반영합니다.
- 스타포스 장비 레벨은 캐릭터의 현재 장착·프리셋 장비에서 자동으로 찾습니다. 못 찾은 장비만 직접 입력합니다.
- 반영한 비용은 목표 진행률, 예상 기간, 누적 수입 그래프(`강화 비용` 선 추가), 홈 이번 주·이번 달 요약과 최근 활동에서 빠집니다.
- 날짜별로 지우고 조건(레벨·MVP·PC방)을 바꿔 다시 불러올 수 있습니다.
- Codex가 만든 이력 정규화·비용 계산을 옮기면서, 이벤트 할인 범위가 `null`인 응답을 처리하지 못하던 문제(실패하던 테스트)를 고쳤습니다.
- 삭제된 시뮬레이터의 스타포스·재설정 비용표는 `features/income/enhancement-model.ts`로 옮겼습니다.

- Codex 재검토에서 나온 문제(레벨 입력란이 입력 도중 사라짐, 빈 날짜에서 화면 오류, 기록장을 바꾼 뒤 이전 조회 결과가 다른 기록장에 저장될 수 있음)를 고쳤습니다.

상세 범위와 한계: [강화 비용 문서](../enhancement-expenses.md)

데이터: `finance.expenses[].calculated`, `finance.ignoredEnhancements` 선택 필드 추가, DB 마이그레이션 없음.

검증: 타입 검사, 테스트 82개(비용 계산·중복 방지·수입 차감·장비 레벨 조회·키 미노출 추가), ESLint, Cloudflare 빌드 통과. 로컬에서 합성 강화 비용으로 목표·그래프·홈·패널 표시와 모바일 폭, 잘못된 키의 오류 안내를 확인했습니다. 실제 넥슨 API 키로 실제 이력을 불러오는 것은 확인하지 못했습니다.
