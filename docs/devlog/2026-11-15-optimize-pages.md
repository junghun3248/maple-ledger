# 2026-11-15 사냥·수입·홈·공통 최적화

작성: Claude (보스 영역은 Codex가 따로 작업)

새 기능 없이 기존 화면의 요청 수와 계산을 줄였습니다.

- **사냥 기록 30초 동기화**: 화면이 가진 revision을 `GET /api/ledger?rev=N`으로 보내고, 서버 기록이 같으면 기록 본문을 읽지도 보내지도 않습니다(`unchanged: true`). 다른 탭에서 기록장을 바꿨으면 전체를 다시 받습니다. 주기 동기화 중에는 화면을 잠그지 않습니다.
- **정적 자원 캐시**: `public/_headers`를 추가했습니다. 글꼴(420KB)·보스 아이콘·초상화는 1주일, OCR 기준 JSON은 하루 캐시합니다. 전에는 매번 서버에 다시 확인했습니다. 해시가 붙은 `/_next/static/*` 규칙도 이 파일로 옮겼습니다.
- **방문자 수**: 탭을 오갈 때마다 집계 요청(DB 쓰기)을 보내던 것을 5분에 한 번으로 줄였습니다.
- **홈·수입 계산**: 요약·최근 활동·누적 수입·예상 기간·그래프 계산을 기록이 바뀔 때만 다시 합니다.
- **그래프 날짜**: 수입 그래프가 브라우저 시간대 대신 다른 화면과 같은 한국 날짜를 씁니다.
- **OCR 보호**: `features/hunting/ocr*`를 `.prettierignore`에 추가해 일괄 포맷에서 빠지도록 했습니다.

글꼴 파일은 넥슨 서체 라이선스상 수정·변환(서브셋, woff2)이 금지되어 그대로 두고 캐시만 늘렸습니다.

검증: 타입 검사, 테스트 84개, ESLint, Cloudflare 빌드, 로컬 통합 테스트(revision 같으면 본문 생략 확인 추가) 통과. 로컬에서 캐시 헤더와 사냥 화면의 `?rev=` 동기화 요청을 확인했습니다.
