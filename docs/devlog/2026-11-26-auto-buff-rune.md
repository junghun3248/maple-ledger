# 2026-11-26 재획 타이머: 버프·룬 쿨타임 등록 없이 자동으로 찾기

작성: Claude

## 내용

- 사용자 요청으로 버프와 룬 쿨타임을 등록 없이 찾습니다. 사용자가 고른 아이콘 두 개를 사용자 게임 화면에서 32×32로 잘라 넣었습니다(`public/wealth-potion.png`: 재물 획득의 비약, `public/rune-cooldown.png`: 룬 쿨타임).
  - 화면 위쪽 절반에서 아이콘을 찾습니다.
  - 버프는 끝나기 10초 전에 "버프 꺼져요", 룬은 쿨타임이 끝날 때 "룬 쓸 수 있어요"라고 알립니다.
  - 각각 켜고 끌 수 있습니다(`autoBuff`, `autoRune` 저장값, 기본 켜짐). 직접 등록은 야누스만 남겼습니다.
- 두 번째 화면 캡처에서 버프 아이콘이 반투명이라는 것을 확인했습니다. 사냥터 배경에 따라 같은 아이콘의 밝기가 크게 달라서, 색 차이로 비교하면 맞는 아이콘도 점수가 낮게 나왔습니다. 고정 아이콘은 두 단계로 찾습니다.
  - 불투명한 검은 테두리로 후보 자리를 고릅니다.
  - 남은 시간 글자(검정·노랑·흰색)를 뺀 채널별 정규화 상관(`iconScore`)으로 점수를 냅니다.
  - 두 캡처 모두에서 정확한 자리를 찾았습니다. 맞는 아이콘은 0.65~1, 다른 아이콘은 0.54~0.65였고, 기준은 0.6입니다. 위쪽 절반 전체를 찾는 데 0.08~0.2초, 둘레만 찾는 데 2~5ms가 걸립니다. 놓쳤을 때는 3초마다 다시 찾습니다.
- 예전에 직접 등록한 버프·룬 알림은 더 이상 감지하지 않습니다.
  - 알림 목록 위에 삭제 안내와 "예전 알림 모두 삭제" 버튼을 띄웁니다.
  - 사용 안내 창 맨 위에도 같은 안내를 넣었습니다. 안내 창 키는 v5로 올렸습니다.
- 쓰지 않게 된 코드를 지웠습니다: 미니맵 룬 감지(`runeMarks`, `observeAppear`), 분만 보이던 예전 버프 등록(`artMask`, `numberVisible`, `registeredDigits`, `padMask`), `sameArea`. 관련 테스트도 함께 지웠습니다.
