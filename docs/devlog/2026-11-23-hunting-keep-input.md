# 2026-11-23 사냥 기록: 기록장 열어도 입력값 유지

작성: Claude

## 내용

- 사냥 기록을 입력하다가 저장을 눌러 기록장 열기 창이 뜨고 로그인하면 입력해 둔 날짜·시간·메소·조각·메모가 지워지던 문제를 고쳤습니다. 기록장을 연 뒤 입력칸을 비우던 처리를 없애고, 수정 중이던 기록 표시만 풀어 새 기록으로 저장되게 했습니다.
- 입력값이 있으면 "기록장을 열었어요. 입력한 내용은 그대로예요. 저장을 눌러 주세요."라고 안내합니다.
- 다른 화면(보스·홈·수입·헥사·스타포스)은 원래 입력값을 지우지 않아 바꾸지 않았습니다.
