# 보스 정산 기존 기능 최적화

작성: Codex

## 범위

- `/boss` 기능과 보스 관련 테스트만 수정했다. 새 기능과 의존성 변경은 없다.
- 무채색 테마, 다크 배경, 서체 범위 및 삭제된 화면 구성은 유지했다.
- `ratio-ocr/`, 공통 컴포넌트, 다른 기능 및 개발일지 인덱스는 수정하지 않았다.
- DB 스키마·마이그레이션 변경 없음. 설치·커밋·배포는 수행하지 않았다.

## 변경 사항

- `BossPage.tsx`: 전체 기록·주간 정산·캐릭터 합계·월간 합계·표시 목록을 메모화했다.
  보드 콜백을 안정화하고 `BossBoard`에 `memo`를 적용해 대화상자·저장 상태 변경 시
  같은 보드를 다시 계산하지 않도록 했다.
- `model.ts`, `BossBoard.tsx`: 결정석·물욕템·합계·가격 누락을 한 번의 정산 순회로
  계산한다. 기존 기록별 BigInt 나눗셈·수수료·미클리어 물욕템 처리는 유지한다.
  보스 아이콘의 중복 검색도 제거했다.
- `BossDataMenu.tsx`: 백업 입출력·파일 입력 ref·기록장 메뉴를 페이지에서 분리했다.
- `AddBossDialog.tsx`: 개별 보스 추가 책임을 분리하고 기존 `RosterDialog` export를 유지했다.
  구성 목록과 선택 목록을 메모화하고 반복 검색을 줄였다. 기존 보스 표시 순서를 유지한다.
- `SchedulerPreview.tsx`: 스케줄러 결과 미리보기를 분리·메모화했다.
  주기별 목록을 재사용하고 월드별 인원 집계를 렌더마다 반복하지 않도록 했다.
- `world-characters.ts`: 월드 필터 후 OCID를 중복 제거한다. 중복 캐릭터 때문에
  서버가 전체 묶음을 거절하거나 같은 캐릭터를 다시 조회하는 문제를 방지한다.
- `server/ledger/nexon.ts`: 유효한 스케줄러를 받은 캐릭터만 이미지를 조회한다.
  실패한 캐릭터당 불필요한 이미지 요청 1회를 줄인다. 자동 동기화의 `images: false`,
  부분 실패 처리 및 이미지 실패 시 기존 프로필 보존은 유지한다.
- `boss.css`, `boss-board.css`: `rg`로 마크업·동적 클래스 사용처를 확인한 뒤
  `.layout`, `.panel`, `.run`, `.character`, `.difficulty`, `.plus`, `.board-columns`,
  `#characters`, `#runs`, `#warning`, `#authError` 관련 미사용 선택자 32개를 제거했다.
  후행 규칙에 덮이는 너비·보드 배치 선언과 동일한 이미지 불투명도 선언도 정리했다.
  현재 반응형 우선순위와 `!important` 규칙은 보존했다.
