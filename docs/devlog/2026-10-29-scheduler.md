# 2026-10-29 — 스케줄러 연결과 칠흑 상자

## 요청

매번 보스를 다시 선택하지 않도록 게임 내 스케줄러에 등록한 주간 보스 목록을 가져오고, 인원과 획득 아이템만 직접 고르는 흐름을 만든다.

## 변경

- 개인 넥슨 API 키로 본인 캐릭터 목록을 조회한다.
- 선택한 캐릭터의 스케줄러에서 등록된 주간 보스와 난이도를 가져온다.
- 파티 인원은 직접 선택하며, 재조회 시 기존 인원·드롭·가격을 유지한다.
- 처치 완료 체크 없이 등록한 보스 결정석과 획득 아이템을 주간 수익에 합산한다.
- 혼돈의 칠흑 장신구 상자에서 나온 아이템을 선택한다. 상자와 내용물을 이중 계산하지 않는다.
- 가엔링 이하의 저가 아이템 및 도미네이터·블랙하트를 신규 선택 목록에서 제외한다. 기존 기록은 유지한다.

## 확인

실제 본인 계정 API에서 캐릭터 목록과 스케줄러 응답을 확인했다. 키와 실제 응답은 저장소에 남기지 않았다. 등록된 주간 보스 필터, 난이도 변환, 같은 주 재조회 중복 방지, 파티 인원 유지, 상자 수익 계산 및 기존 기능을 포함한 22개 테스트와 배포 빌드가 통과했다.

## 제약

스케줄러는 파티 인원을 제공하지 않는다. 기존 기록의 처치 체크 여부와 관계없이 등록한 보스는 수익에 포함한다. 가격표에 없는 보스는 누락 사실을 표시하고 자동 금액 계산에서 제외한다. 현재 조회는 실시간 목록을 사용한다.

## 사용 안내 추가

넥슨 Open API 링크를 메인 페이지(https://openapi.nexon.com/ko/)로 연결하고, 계정 로그인·애플리케이션 등록·키 복사·캐릭터 조회·보스 가져오기 순서를 연결 창에 표시했다. 발급 절차는 넥슨 공식 사전 준비 가이드를 확인했다.

칠흑 상자 버튼과 아이템 목록에 사용자 제공 이미지를 바탕으로 분리한 상자 아이콘을 적용했다. 원본 툴팁 스크린샷은 공개 소스에 포함하지 않는다.

## 주간 수익 중심으로 간소화

사용자 요청에 따라 처치 완료 체크를 제거했다. 인원과 물욕템·판매가만 선택하면 등록한 모든 보스의 결정석과 아이템 수익이 날짜·주·월 합계에 반영된다. 기존 저장 형식은 호환성을 위해 유지한다.
