# 2026-11-14 메이플 서체와 검색 노출

작성: Claude

## 서체

- 넥슨 무료 서체 메이플스토리 Bold를 `public/fonts`에 원본 그대로 두고 제목·메뉴·주요 금액에 적용했습니다. 본문은 가독성을 위해 기본 서체를 씁니다. 라이선스 안내는 `public/fonts/README.md`에 있습니다.
- 페이지마다 달랐던 본문 서체(Noto Sans KR, Arial, system-ui)를 하나의 서체 묶음으로 통일했습니다.

## 검색 노출 ("메이플 가계부")

- 기본 제목을 `메소저장소 - 메이플 가계부`로 바꾸고, 페이지 제목에 `메이플 가계부 메소저장소`를 붙였습니다.
- 설명문과 키워드에 메이플 가계부·보스 결정석 계산기 등을 넣고 Open Graph 제목을 맞췄습니다.
- 사이트 이름 구조화 데이터(WebSite, alternateName `메이플 가계부`)를 추가했습니다.
- 상단 로고 옆에 `메이플 가계부` 문구를 보이게 했습니다.

검색 순위는 Google의 재수집 후 반영됩니다. Search Console에서 사이트맵 제출과 색인 생성 요청을 하면 더 빨라집니다.

검증: 테스트 78개·타입 검사·Cloudflare 빌드 통과, 페이지 HTML의 제목·구조화 데이터 확인, 글꼴 파일 200 응답 확인.
