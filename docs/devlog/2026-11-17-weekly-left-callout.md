# 2026-11-17 수요일 남은 보스 알림을 한 줄 안내로

작성: Claude

사용자가 보여 준 주간 보스 안내 예시처럼, 수요일 알림을 한 줄 문구로 바꿨습니다.

- `진짜 안 도실 건가요? (결정석) 113억에 (아이템 아이콘들)을 추가로 얻을 수도 있습니다.` 형식입니다.
- 결정석 합계는 1억 이상이면 `111.7억`처럼 짧게 씁니다. 아이콘에 마우스를 올리면 아이템 이름과 나오는 보스가 보입니다.
- 아이콘에는 물욕템만 보여 주고, 소울 에테르·연마석 같은 재료는 뺐습니다.
- 아래 작은 줄에 초기화 안내와 남은 보스(캐릭터·난이도·보스)를 이어서 적습니다.

검증: 타입 검사, 테스트 89개, ESLint, Cloudflare 빌드 통과. 로컬에서 수요일 판정을 잠시 켜고 홈 화면 표시를 확인한 뒤 되돌렸습니다.

## 추가: 물욕템이 없을 때 연마석 표시

노멀 대적자 등 남은 보스에 물욕템이 하나도 없으면 아이콘이 비어 보였습니다. 이때는 생명·신념의 연마석을 대신 보여 줍니다. 물욕템이 하나라도 남아 있으면 지금처럼 물욕템만 보여 주고, 소울 에테르는 계속 뺍니다.

검증: 타입 검사, 테스트 90개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.

## 추가: 에픽빔 기준으로 아이템 고르기

재료 이름으로 거르던 방식을 바꿔, 드롭할 때 에픽빔이 뜨는 아이템만 아이콘으로 보여 줍니다. 사용자 확인 기준으로 1~3단계 소울 에테르와 파풀라투스 마크만 에픽빔이 없고, 나머지(연마석, 4단계 소울 에테르, 익셉셔널 해머, 칠흑 상자 등)는 모두 표시합니다. 목록은 `features/boss/weekly-left.ts`의 `noEpicBeam`에서 관리합니다. 아이콘이 많아지면 줄을 바꿔 표시합니다.

검증: 타입 검사, 테스트 90개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.

## 추가: 귀한 아이템 3개만 아이콘으로

에픽빔 아이템을 전부 보여 주니 줄이 길어져서, 보내 주신 예시처럼 간결하게 귀한 순서로 최대 3개만 아이콘으로 보여 줍니다(`DROP_LIMIT`). 순서는 에테르넬급 → 창세의 뱃지 → 나머지 칠흑 → 익셉셔널 해머·칠흑 상자·4단계 에테르 → 그 밖(연마석 등)입니다. 아랫줄은 남은 보스 개수만 적고, 마우스를 올리면 캐릭터·보스 목록이 보입니다.

검증: 타입 검사, 테스트 91개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.

## 추가: 안내 문구 한 줄만

아랫줄(초기화 안내·남은 보스 수·보스 정산 링크)을 없애고 `진짜 안 도실 건가요? (결정석) N억에 (아이콘)을 추가로 얻을 수도 있습니다.` 한 줄만 남겼습니다. 남은 보스 목록은 문구에 마우스를 올리면 보입니다.

검증: 타입 검사, 테스트 91개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.

## 추가: 아이콘 우선순위를 사용자 지정 순서로

사용자가 정한 순서로 바꿨습니다(`features/boss/weekly-left.ts`의 `priority`). 1순위: 오만의 원죄, 굶주리는 핏빛 원혼, 황홀한 악몽, 근원의 속삭임, 불멸의 유산, 죽음의 맹세, 익셉셔널 해머 5종, 컴플리트 언더컨트롤. 2순위: 4단계 소울 에테르, 몽환의 벨트, 마도서, 거대한 공포, 고통의 근원. 3순위: 생명·신념의 연마석, 커맨더 포스 이어링, 루즈 컨트롤 머신 마크, 마력이 깃든 안대. 같은 순위 안에서도 적힌 순서를 따르고, 목록에 없는 미트라의 분노·창세의 뱃지·칠흑 상자는 맨 뒤에 둡니다. 컴플리트 언더컨트롤은 1·2순위에 모두 적혀 있어 1순위로 두었습니다.

검증: 타입 검사, 테스트 91개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.
