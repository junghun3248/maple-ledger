# 2026-11-17 수요일 남은 보스 알림을 한 줄 안내로

작성: Claude

사용자가 보여 준 주간 보스 안내 예시처럼, 수요일 알림을 한 줄 문구로 바꿨습니다.

- `진짜 안 도실 건가요? (결정석) 113억에 (아이템 아이콘들)을 추가로 얻을 수도 있습니다.` 형식입니다.
- 결정석 합계는 1억 이상이면 `111.7억`처럼 짧게 씁니다. 아이콘에 마우스를 올리면 아이템 이름과 나오는 보스가 보입니다.
- 아이콘에는 물욕템만 보여 주고, 소울 에테르·연마석 같은 재료는 뺐습니다.
- 아래 작은 줄에 초기화 안내와 남은 보스(캐릭터·난이도·보스)를 이어서 적습니다.

검증: 타입 검사, 테스트 89개, ESLint, Cloudflare 빌드 통과. 로컬에서 수요일 판정을 잠시 켜고 홈 화면 표시를 확인한 뒤 되돌렸습니다.

## 추가: 물욕템이 없을 때 연마석 표시

노멀 대적자 등 남은 보스에 물욕템이 하나도 없으면 아이콘이 비어 보였습니다. 이때는 생명·신념의 연마석을 대신 보여 줍니다. 물욕템이 하나라도 남아 있으면 지금처럼 물욕템만 보여 주고, 소울 에테르는 계속 뺍니다.

검증: 타입 검사, 테스트 90개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.
