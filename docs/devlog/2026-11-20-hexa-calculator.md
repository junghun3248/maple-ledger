# 2026-11-20 헥사 계산기

작성: Claude

메이플린드 헥사 계산기를 참고해 새 메뉴 `헥사`(`/hexa`)를 추가했습니다.

- **코어 불러오기:** 보스 정산과 같은 넥슨 API 키로 260레벨 이상 캐릭터를 고르면 `character/hexamatrix`에서 장착 코어의 이름·레벨·종류를 읽습니다(서버 액션 `nexon-hexa`, 키는 브라우저에만 저장).
- **계산:** 코어별 목표 레벨까지 필요한 솔 에르다·조각과 조각 가격(기본 600만 메소, 변경 가능)으로 환산한 메소를 보여 줍니다. 가진 재료를 넣으면 부족분과 코어별로 어디까지 올릴 수 있는지도 보여 줍니다.
- **비용표:** `features/hexa/costs.ts`. 스킬·3rd 스킬·마스터리·강화·공용(솔 야누스·솔 헤카테)·직업군 공용 코어 6종이며 나무위키 HEXA 매트릭스 표(2026-11-14 수정본)를 옮겼습니다. 테스트에서 0→10·20·30 누적값과 대조합니다.
- **코어 종류:** 넥슨 응답의 종류·이름으로 고르고, 3rd 스킬 코어처럼 구분이 안 되는 경우는 화면에서 바꿀 수 있습니다. 아직 열지 않은 코어는 직접 추가합니다. 목표 레벨과 종류는 캐릭터별로 브라우저에 기억합니다.
- **목표 저장:** 필요한 메소(가진 조각을 뺀 부족분)를 헥사 화면에서 바로 열린 기록장의 목표로 저장합니다. 이름을 바꿀 수 있고, 메모에 솔 에르다·조각 개수를 남깁니다. 기록장이 닫혀 있으면 이 화면에서 엽니다. (처음에는 수입·목표 화면의 새 목표 창으로 넘겼으나 사용자 요청으로 헥사 화면 안에서 저장하도록 바꿨습니다.)
- **메뉴:** 메뉴가 다섯 개가 되어 761~1080px 폭에서는 메뉴 아이콘과 부제를 숨겨 한 줄에 맞춥니다.

남은 확인: 실제 넥슨 응답에서 3rd 스킬 코어와 직업군 공용 코어의 `hexa_core_type` 값은 아직 확인하지 못했습니다.

검증: 타입 검사, 테스트 97개, ESLint, Prettier, Cloudflare 빌드 통과. 로컬에서 직접 추가한 코어로 계산·목표 저장·모바일 화면과 761~1100px 메뉴 넘침을 확인했습니다. DB 마이그레이션 없음.

## 추가: 게임 HEXA 매트릭스 모양 판

사용자 요청으로 코어 목록 표를 게임 HEXA 매트릭스처럼 생긴 판(`features/hexa/HexaBoard.tsx`)으로 바꿨습니다.

- 스킬(6칸)·마스터리·강화·공용(각 4칸) 네 묶음에 육각형 칸을 놓고, 칸마다 아이콘·현재 레벨·목표 레벨을 표시합니다. 그림은 메이플린드 이미지를 쓰지 않고 CSS·SVG로 직접 그렸습니다.
- 칸을 누르면 오른쪽에 그 코어의 현재·목표 레벨(숫자·슬라이더), 비용 종류, 필요 재료, 보유 재료로 도달 가능한 레벨이 나옵니다. 자물쇠 칸을 누르면 아직 열지 않은 코어를 그 묶음으로 추가합니다.
- 아이콘은 `nexon-hexa`가 `character/skill?character_skill_grade=6`도 읽어 코어 이름이나 연결 스킬 이름이 같은 스킬의 아이콘을 붙입니다. `open.api.nexon.com/static/maplestory/` 주소만 허용하고, 스킬 조회가 실패해도 코어 계산은 그대로 보여 줍니다.

검증: 타입 검사, 테스트 98개, ESLint, Cloudflare 빌드 통과. 로컬에서 직접 추가한 코어로 판·선택·합계를 1280px와 375px 폭에서 확인했습니다(가로 넘침 없음). 실제 API 키로는 확인하지 못했습니다.
