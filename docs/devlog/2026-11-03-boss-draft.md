# 2026-11-03 보스 초안 보존과 비밀번호 조건

- 새 기록장 비밀번호 최소 길이를 9자에서 4자로 완화했다. 기존 비밀번호는 그대로 사용할 수 있다.
- 보스 정산표 변경을 브라우저 저장소에 즉시 저장하고 새로고침·메뉴 재진입 시 복원한다.
- 로그인하지 않은 초안과 기록장별 초안을 분리한다. 서버 저장은 기존 충돌 검사를 유지한다.
- 기록장 저장 버튼을 데이터 메뉴 밖에도 노출했다. 기기 저장과 다른 기기 동기화의 차이를 상태 메시지로 안내한다.
- 저장 공간 오류는 저장 성공으로 표시하지 않는다. 개인정보인 키와 비밀번호는 초안에 포함하지 않는다.
