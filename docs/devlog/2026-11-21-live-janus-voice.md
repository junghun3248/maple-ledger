# 2026-11-21 재획 타이머: 야누스·10초 전 음성 알림·룬 색 감지

작성: Claude

## 바뀐 점

- **모든 시간 알림은 끝나기 10초 전에 한 번만** 울립니다. "꺼졌어요"나 다시 썼을 때의 알림은 없앴습니다. 다시 써서 남은 시간이 15초 넘게 늘어나면 알리지 않고 다음 알림만 준비합니다.
- **음성 알림:** 브라우저 내장 음성(Web Speech API, 한국어)으로 "버프 꺼져요", "야누스 꺼져요", "부스터 꺼져요", "룬 떴어요"라고 말합니다. 서버로 보내는 것은 없고, 한국어 음성이 없으면 알림음으로 대신합니다.
- **야누스 추가:** 버프 칸 전체를 영역으로 잡으면 야누스 아이콘이 어디로 밀려도 찾고, 아이콘 위 "1:11"을 읽습니다. 버프 UI에서 따로 빼지 않아도 됩니다.
- **부스터:** "남은시간" 옆 숫자("53.73")를 읽어 10초 전에 알립니다.
- **버프:** 흰 분 숫자가 보이면 알릴 준비를 하고, 1분 아래의 노란 초 숫자를 읽어 10초 전에 알립니다. 초 숫자를 못 읽었을 때만 숫자가 사라지는 5초 전에 한 번 알립니다.
- **룬:** 아이콘 등록 없이 미니맵만 고르면 보라색 마름모 픽셀(10px 이상)로 감지합니다. 초록 원·노란 점·분홍빨강 점은 세지 않습니다.
- 등록 3단계에서 고른 숫자 칸을 바로 읽어 "읽은 시간 1:14 (74초)"처럼 보여 주고, 감지 중에도 마지막으로 읽은 글자를 보여 줍니다.

## 구현 메모

- 숫자 읽기: 검은 테두리 옆 흰색·노란색 픽셀에서 시작해 같은 색 계열(번진 가장자리 포함)로 획을 채운 흑백 마스크를 4배로 키워, 사냥 기록 사진 인식과 같은 Tesseract(숫자 전용 작업자)로 읽습니다. 글자 색은 흰색·노란색 중 많은 쪽만 남겨, 숫자 테두리에 닿은 아이콘 그림(야누스의 노란 고리 등)을 뺍니다. 숫자 칸은 둘레 3px를 넓혀 읽습니다.
- 잘못 읽기 거르기: 감지마다 받는 모양을 정했습니다(야누스 "m:ss", 부스터 "ss.ss", 버프 초 1~59). 읽은 값은 이전 추정과 2.5초 안으로 맞거나 두 번 연속 서로 맞을 때만 믿고, 그 사이에는 시각으로 줄여 갑니다.
- 숫자 읽기(약 0.3~1초)는 감지(0.5초마다)를 막지 않도록 따로 돌리고, 읽은 화면이 찍힌 시각 기준으로 계산합니다.
- 가려진 탭에서는 `image.decode()`가 끝나지 않아 감지가 멈췄습니다. 아이콘은 `createImageBitmap`, 스냅샷은 `load` 이벤트로 바꿨습니다.
- 2단계 저장값(`mode`만 있는 감지)은 읽을 때 `kind`(rune·buff·booster)로 바꿉니다.
