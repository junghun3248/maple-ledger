# 2026-11-14 흰색·검정 테마와 화면 간결화

작성: Claude

초록색 위주라 칙칙하다는 의견에 따라 사이트 전체를 무채색 라이트/다크 테마로 바꾸고, 반복되는 설명문을 줄였습니다. 기능과 저장 데이터는 바꾸지 않았습니다.

## 테마

- `components/ledger/theme.css`에 공통 색상 토큰(배경, 카드, 테두리, 글자, 강조, 성공·경고)을 두었습니다. 기본은 기기 설정(라이트/다크)을 따릅니다.
- 다크 모드 배경은 사용자 요청 색상 `#404040`을 기준으로 카드와 테두리를 한 단계씩 밝게 했습니다.
- 상단 바 오른쪽 버튼으로 `기기 설정 → 라이트 → 다크`를 바꿀 수 있고 브라우저에 기억합니다. 첫 화면 전에 적용해 깜빡임이 없습니다.
- 12개 CSS 파일에 흩어진 초록 계열 고정 색 약 350곳을 역할(배경·글자·테두리)과 밝기 기준으로 토큰에 연결했습니다. 보스 난이도 배지처럼 의미가 있는 색은 유지했습니다.
- 강조색은 검정(다크에서는 흰색)입니다. 클리어한 보스만 초록 계열 성공 색으로 구분합니다.
- 차트 선, 대화상자 배경과 뒤 배경도 테마를 따릅니다.

## 간결화

- 페이지 제목을 메뉴 이름과 맞추고 부제목을 없앴습니다(사냥 기록, 보스 정산, 자산·지출).
- 보스: `WEEKLY REVENUE`·`MY CHARACTERS` 표기, 요약 카드 보조 설명, 보드 안내문을 없앴습니다. 보스 카드 안내는 툴팁으로 옮겼습니다. 버튼명을 줄였습니다(`저장`, `＋ API로 추가`, `표시 선택`, `보스 변경`).
- 사냥: 단계 배지, 반복 안내, 캘린더 보조 문구를 없애고 촬영 안내를 한 줄로 줄였습니다. PC에서는 모바일용 바로가기 버튼을 숨깁니다.
- 자산·지출: 긴 계산 설명 문단을 한 줄 공식과 짧은 안내로 바꾸고, 차트 범례를 색 견본으로 표시합니다.
- 숫자는 고정폭 숫자로 표시해 금액 정렬을 맞췄습니다.

## 반응형

- 모바일 보스 화면의 `데이터` 버튼 줄바꿈과 캐릭터 버튼 넘침을 고쳤습니다.
- 모바일에서 건의·버그 제보 버튼을 아이콘만 표시해 본문 버튼을 덜 가립니다.
- PC 1280px, 모바일 390px에서 사냥·보스·자산·시뮬레이터 화면의 가로 넘침이 없는 것을 확인했습니다.

## 검증

- 자동 테스트 90개, TypeScript, Cloudflare 빌드 통과. ESLint 신규 경고 없음.
- 로컬 Worker + D1 통합 테스트 통과.
- 라이트·다크 각 화면, 보스 상세·API 가져오기 대화상자, 테마 전환 후 새로고침 유지 확인.
- OCR 관련 파일은 수정하지 않았습니다.
