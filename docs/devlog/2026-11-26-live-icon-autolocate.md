# 2026-11-26 재획 타이머: 버프·야누스 위치 자동 찾기와 아이콘 전체에서 시간 읽기

작성: Claude

## 내용

- 사용자 게임 화면(1366×771 창 모드)을 캡처해 감지 코드를 직접 돌려 보니, "분+초" 표시에서도 10분 넘게 남은 버프는 분만(`23`, `51`) 보였습니다. 등록 3단계에서 이 좁은 숫자를 감싸면 나중에 `9:59`처럼 넓어질 때 글자가 잘려 끝까지 못 읽었습니다.
- 숫자 칸을 따로 고르지 않고, 아이콘 안쪽(테두리 2px 제외) 전체에서 노란 남은 시간 글자만 골라 읽습니다(`clockMask`). 흰 겹침 수(`13`)·아이콘 그림·주황 배경은 들어오지 않고, 한 픽셀짜리 잡티는 지웁니다. 예전에 등록한 버프·야누스도 다시 등록하지 않아도 이 방식으로 읽습니다(분만 보이던 예전 등록은 그대로).
- 버프·야누스 아이콘은 고른 영역과 관계없이 게임 화면 위쪽 절반에서 찾습니다. 찾은 뒤에는 둘레(아이콘 두 칸)만 보고, 놓치면 2초마다 위쪽 절반 전체를 다시 찾습니다. 실제 화면에서 아래쪽 스킬 단축키 칸에 같은 그림과 0.90~0.94로 비슷한 곳이 있어, 아래쪽 절반은 보지 않습니다.
- 등록은 1단계 대충 영역(확대용) → 2단계 아이콘 → 3단계 읽은 시간 확인으로 바뀌었습니다. 3단계에서 드래그하지 않습니다.
