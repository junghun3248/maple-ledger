# 2026-11-27 사이트 전체 UI/UX 점검·정리

작성: Claude

## 점검 방법

- 개발 서버에서 모든 공개 페이지(홈, 사냥 기록, 보스 정산, 수입·목표, 스타포스, 헥사, 건의·제보)를 1280·1440px과 375px에서 열어 봤습니다. 재획 타이머(사냥 기록 위쪽)는 PC 전용이라 모바일 배치는 손대지 않았습니다.
- 가로 넘침, 입력 라벨, 본문 폭·여백, 글자 대비(WCAG AA, 라이트·다크)를 스크립트로 쟀고, 하드코딩 색과 쓰이지 않는 CSS는 코드에서 찾았습니다.
- 테스트용 기록장을 로컬 D1에만 만들어 사냥·보스 데이터가 있는 화면도 확인했습니다.

## 손대지 않은 것

- 재획 타이머의 모바일 배치(PC 전용). 문구 한 줄만 고쳤습니다.
- 차트(Recharts) 막대 색 `#6a87b1`은 SVG 속성이라 그대로 두고, 범례·배지는 같은 값의 `--boss-tone` 토큰을 씁니다.
- 헥사 보드의 보라색 배경은 화면 고유 디자인이라 유지했습니다.
- `components/ledger/ledger.css`에 보스·사냥 전용 규칙이 섞여 있는 구조는 기능 폴더로 옮기는 별도 정리 대상으로 남깁니다.
