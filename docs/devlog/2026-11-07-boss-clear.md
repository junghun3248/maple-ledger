# 보스 카드 클리어 표시

스케줄러에서 이미 가져오고 저장하던 클리어 상태를 보스 모아보기 카드에 표시합니다.
완료된 보스는 연두색 배경과 체크·클리어 문구로 구분하고, 미완료 보스는 흰색을 유지합니다.
스크린 리더에도 완료 여부를 전달합니다. 카드를 누르면 기존처럼 정산 상세가 열립니다.

주간·월간 기록 각각의 저장된 상태를 표시하며 수익 계산과 파티 인원은 변경하지 않습니다.
최신 게임 상태를 반영하려면 스케줄러를 다시 가져와 기록장에 저장해야 합니다.

타입 검사, 관련 스케줄러·보드·수익 테스트와 Cloudflare 빌드로 검증합니다.
