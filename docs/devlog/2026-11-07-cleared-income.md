# 클리어 기준 보스 수익

보스 결정석은 저장된 클리어 상태가 true인 경우에만 수익에 반영합니다.
스케줄러 재가져오기로 완료 상태가 갱신되면 전체·캐릭터·월간 합계와 수입 추이에
같은 기준이 적용됩니다. 획득 체크한 물욕템은 기존 수수료·파티 분배 방식으로 반영합니다.

게임 상태의 실시간 자동 감시는 아닙니다. 최신 스케줄러 정보를 다시 가져와
기록장에 저장해야 다른 기기에도 반영됩니다. 기존 기록의 완료 상태가 false이면
그 결정석 금액은 이제 합계에서 제외됩니다. 원본 기록과 결정석 가격은 보존합니다.

미클리어 제외, 클리어 전환 시 증가, 물욕템 독립 합산 회귀 테스트를 확인합니다.
