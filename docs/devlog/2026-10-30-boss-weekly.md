# 2026-10-30 — 보스 메뉴를 주간 수익 중심으로 정리

- 내 캐릭터 ＋에서 넥슨 스케줄러 연결을 바로 시작한다. API 없이 닉네임으로 추가하는 기능은 연결 창의 보조 버튼으로 제공한다.
- 목요일~수요일 주간 탐색, 전체 수익, 선택 캐릭터 수익과 결정석·물욕템 구분을 제공한다.
- 같은 주의 다른 날짜에 등록한 보스도 한 화면에 보여준다.
- 처치 완료 체크를 제거하고 등록한 보스의 결정석을 바로 합산한다. 인원과 획득 아이템·판매가만 입력한다.
- Open API 메인 링크와 발급·입력 가이드를 제공한다.
- 사용자 제공 사진을 바탕으로 분리한 칠흑 상자 아이콘을 적용한다. 원본 스크린샷은 공개하지 않는다.
- 사냥 가계부와 OCR 화면은 수정하지 않는다.

넥슨 API 키와 실제 응답, 사용자 기록은 공개 소스에 포함하지 않는다. 매주 기록은 스케줄러를 가져오거나 직접 구성해 저장하며, 이전 주 드롭을 다음 주에 복사하지 않는다.
