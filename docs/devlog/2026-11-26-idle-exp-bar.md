# 2026-11-26 재획 타이머: 동꼽 방지 경험치 바 찾기와 9초

작성: Claude

## 내용

- 사냥 중에도 "캐릭터 움직이세요"가 자주 울린다는 제보를 받았습니다. 사용자 화면을 캡처해 보니 경험치 숫자 줄은 맞게 찾고 있었습니다. 원인은 대기 시간으로 봤습니다. 대부분의 사냥터는 몬스터가 7~8초마다 다시 나와서, 다 잡고 기다리는 동안은 경험치가 오르지 않습니다. 5초 기준은 이 대기 시간보다 짧아 사냥 중에도 울렸습니다. 기준을 9초로 늘렸습니다.
- 사용자가 해상도마다 경험치 바 위치가 다르다고 짚어 주었습니다. 그래서 공유 화면 아래쪽에서 흰 숫자 줄을 찾기 전에, 화면 전체에서 연두색 경험치 바를 먼저 찾습니다. 채움이 같은 x에서 시작하거나 끝나며 5~14줄 이어진 띠 중 가장 아래 것을 고릅니다. 게임 창이 작거나 전체 화면을 공유해 바가 맨 아래에 있지 않아도 찾습니다. 비교 칸은 그 줄 전체(숫자 + 채움 길이)입니다.
- 경험치가 거의 0%여서 채움이 24px보다 짧으면 예전 방식(아래쪽 흰 숫자 줄)으로 찾습니다. 미리보기는 바 가운데 40%만 보여 줍니다.
- 사용 안내가 바뀌어 "다시 보지 않기" 키를 v4로 올렸습니다.
