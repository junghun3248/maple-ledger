# 2026-11-21 사냥 기록 화면을 재획 타이머 중심으로

작성: Claude

## 바뀐 점

- 사냥 기록 화면(`/hunting`) 맨 위에 재획 타이머를 넣었습니다. 왼쪽에 재획 세션·화면 공유·메소/조각 스냅샷·음성 설정, 오른쪽에 버프·야누스·부스터·룬 알림이 있고, 그 아래에 월 합계·기록 입력·캘린더가 그대로 있습니다.
- 재획을 끝내면 다른 화면으로 가지 않고 같은 화면의 기록 입력칸에 날짜·사냥 시간·읽어 둔 메소/조각을 채우고 그 칸으로 스크롤합니다. 저장은 사용자가 숫자를 확인한 뒤 합니다(확인 문구 "숫자를 확인했어요.").
- 사용자 요청으로 스크린샷 업로드 입력을 없앴습니다(화면 공유 스냅샷으로 대체). `ScreenshotReader.tsx`, `CaptureGuide.tsx`, `capture-guide.css`와 사진 입력 전용 CSS를 지웠습니다. 메소·조각 인식 엔진(`features/hunting/ocr`)은 스냅샷과 남은 시간 읽기에서 계속 씁니다.
- `/hunting/live`는 `/hunting`으로 보냅니다(307). 사이트맵에서 뺐고, 페이지 제목은 "재획 타이머·사냥 기록"입니다.
- `LiveHelper`를 사냥 기록 화면에 들어가는 `LivePanel`로 바꾸고, 화면 사이에 값을 넘기던 `localStorage` 키(`maple-hunt-prefill`)와 `readPrefill`을 없앴습니다.

## 남은 문제
