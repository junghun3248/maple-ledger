# 2026-11-17 클리어 동기화가 스케줄러 난이도를 따르도록

작성: Claude

정산표에는 노멀 벨로나로, 게임 스케줄러에는 하드 벨로나로 등록되어 있으면 보스·난이도가 맞지 않아 넥슨 클리어가 반영되지 않았습니다(사용자가 난이도를 직접 바꾼 뒤에야 반영됨).

- 자동 동기화(`features/boss/auto-sync.ts`)에서 같은 난이도 기록이 없고 같은 보스가 다른 난이도로 들어 있으면, 스케줄러 난이도와 그 난이도의 결정석 가격으로 바꾼 뒤 클리어 여부를 반영합니다.
- 파티 인원·수수료는 유지하고, 난이도마다 다른 솔로 비율 값은 지웁니다.
- 클리어를 직접 바꾼 기록이나 드롭을 적은 기록은 사용자가 정리한 것으로 보고 바꾸지 않습니다.

검증: 타입 검사, 테스트 92개, ESLint, Cloudflare 빌드 통과. DB 마이그레이션 없음.
