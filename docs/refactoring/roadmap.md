# 단계별 실행 계획

1. Prettier·AGENTS 설정과 현재 구조·목표·명세 문서 작성.
2. 원본과 미완료 변경을 민감정보 검사 후 Git에 보존. 공개 main에 기준선 게시 후 backup 및 refactor 브랜치 생성.
3. 기존 테스트·타입·Lint 기준선 기록.
4. 서버 서비스를 server로 이동하고 HTTP 진입점은 app/api에 유지. API 계약과 검증을 contracts에 추출.
5. 보스 수익 및 스케줄러 순수 로직을 기능 모듈로 타입화.
6. 보스 UI를 React로 이전: 캐릭터 선택 → 보스 → 물욕템 → 저장 순서로 검증.
7. 사냥 UI를 독립 단계로 이전: OCR 엔진 보존 후 캘린더·입력·저장 연결 검증.
8. 동적 참조와 배포 경로까지 조사해 미사용 코드·패키지 정리.
9. 전체 검증, 운영 반영 확인 후 대체 완료 레거시만 제거.

각 단계는 독립 커밋으로 남기며 실패 단계만 되돌린다. 원본 브랜치는 유지한다. 준비 단계와 서버 추출만으로 전체 React 이전 완료를 선언하지 않는다.

## 실행 현황

1~3단계 완료. 원본은 backup/pre-refactor-2026-10-31, 작업은 refactor/architecture-2026-10-31 브랜치에서 보관한다. 4단계 서버 서비스 추출 및 사냥 계약 분리는 완료했으며 인증·저장 세부 분리는 남아 있다. 5~9단계는 미완료다.
