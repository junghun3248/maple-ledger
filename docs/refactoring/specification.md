# 기능 보존 명세

## 수익

결정석은 수수료 0%, 파티 인원으로 나눈다. 아이템에만 수수료를 적용한다. 처치 체크로 수익을 제외하지 않는다. 주간 범위는 목요일부터 수요일이다.

## 스케줄러

API 전투력 10,000,000 초과만 신규 가져오기 목록에 표시한다. 여러 캐릭터를 선택하고 일부 실패를 구분한다. 동일 주 재조회는 인원·가격·아이템·기존 날짜를 유지한다. 기존 기록을 필터 때문에 삭제하지 않는다.

## 저장·인증

기존 기록장 이름, 비밀번호, 세션, 버전 충돌 및 백업 호환성을 유지한다. DB 마이그레이션 없이 레이어를 분리한다. 키와 사용자 기록은 Git이나 로그에 포함하지 않는다.

## 사냥

캘린더 날짜 선택, 이미지 인식 위치 조정, 메소·조각 OCR, 직접 수정, 저장 및 월 합계의 결과가 동일해야 한다.

## 검증

각 단계에서 관련 테스트·타입 검사·ESLint·포맷 검사·빌드를 실행한다. UI 이전은 데스크톱·모바일 및 키보드, 저장·복원, 오류 메시지까지 확인한다.
