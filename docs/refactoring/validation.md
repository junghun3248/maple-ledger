# 검증 현황

## 기준선

- 타입 검사: HTML raw import 선언 누락 2개.
- 서버 ESLint: any 및 prefer-const 23개.
- 기존 자동 테스트: 30개 통과(OCR 포함).

## 서버 분리 단계

- 서버 구현을 server/ledger로 이동하고 app/api에 HTTP 진입점 유지.
- 기존 내부 경로는 호환 재수출 유지. 기존 데이터 스키마 변경 없음.
- 사냥 기록 계약과 Zod 검증을 contracts/ledger에 추출.
- DB 행 타입과 요청·응답 타입 분리.
- 전체 타입 검사 통과.
- server, contracts, app/api/ledger 및 추가 DB 타입 ESLint 통과.
- 전체 자동 테스트 30개 통과 후 넥슨 타입 변경 관련 8개 재검증 통과.
- 포맷은 변경 영역만 적용. 전체 레거시 포맷 일괄 적용은 미실시.

## 남은 단계

- 실제 API 브라우저 검증과 다중 캐릭터 선택 운영 배포.
- HTTP 서비스의 인증·저장 책임 추가 분리.
- 보스·사냥 React UI 이전 및 브라우저 검증.
- 순수 프론트엔드 모델 타입화 및 레거시 참조 정리.
- 전체 프로젝트 ESLint 기준선 조사, 의존성 사용 조사.
- 최종 운영 배포와 레거시 제거.

이 단계는 전체 리팩토링 완료가 아니다. 운영 사이트와 원본 보존 브랜치는 변경하지 않는다.

## 인증 책임 분리

인증 암호 처리·쿠키·세션을 auth.ts로, 요청 제한을 rate-limit.ts로, DB 연결을 db/ledger.ts로 추출했습니다. 전체 테스트 30개, 타입 검사 및 변경 영역 ESLint 통과. React UI 이전과 운영 배포는 여전히 미완료입니다.
