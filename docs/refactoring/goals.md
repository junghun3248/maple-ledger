# 목표 및 완료 기준

- 기존 사냥 OCR, 캘린더, 인증, 저장, 보스 수익 및 스케줄러 동작 보존.
- Next.js App Router와 React 중심으로 UI를 단계적으로 이전.
- contracts, features, server 경계를 분리하고 요청을 런타임 검증.
- 기존 URL과 기록 형식, 비밀번호 해시, 쿠키, 저장 충돌 처리 유지.
- 테스트, 타입 검사, 변경 영역 ESLint·Prettier, 빌드 및 브라우저 검증.
- 검증한 단계만 완료 처리하고 기존 오류와 신규 오류를 구분.

프레임워크 교체, DB 초기화, 새로운 기능 추가 및 근거 없는 패키지 제거는 목표에서 제외한다.
