넥슨 스케줄러 연결

본인 API 키로 게임 내 스케줄러에 등록한 주간 보스를 가져옵니다. 키는 이 창이 열려 있는 동안만 사용하며 서버·기록장에 저장하지 않습니다.

API 키 발급·입력 방법넥슨 Open API 열기 ↗
  1. 넥슨 Open API에서 캐릭터가 있는 넥슨 계정으로 로그인하세요.
  2. 내 애플리케이션 → 애플리케이션 등록에서 게임을 메이플스토리로 선택하고 안내에 따라 등록하세요. 개인 조회용이라면 개발 단계로 시작할 수 있어요.
  3. 등록한 애플리케이션의 상세 페이지에서 API Key 전체를 복사하세요. 이미 발급한 키가 있으면 그대로 사용해도 돼요.
  4. 아래 입력칸에 붙여넣고 내 캐릭터 조회를 누르세요.
  5. 캐릭터를 고른 뒤 등록한 주간 보스 가져오기 → 이 목록을 정산표에 추가를 누르세요.

먼저 게임 내 스케줄러에 가는 보스를 등록해 주세요. 가져온 뒤 파티 인원과 획득 아이템을 선택하고, 기록장에 저장하면 됩니다.

인원은 가져온 뒤 보스 옆에서 직접 선택하세요. 같은 주의 기존 기록·가격·인원은 유지합니다. 등록한 모든 보스의 결정석과 선택한 획득 아이템이 수익에 합산됩니다.
